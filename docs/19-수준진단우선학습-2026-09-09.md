# 수준 진단 후 첫 교재 배정

학생 수강 페이지와 학습 노트 홈에서 수준 진단을 안내한다. 진단은 영어·한국어 안내, 20문항, 모르겠어요 선택지, 처리 중 중복 클릭 방지, 실패 시 재시도를 제공한다. 답안 기록을 서버에서 순서 검증하고 다시 채점하며 클라이언트 점수를 신뢰하지 않는다.

진단 기록이 없는 신규 학생의 첫 수업 및 첫 교재 열기를 서버에서 차단한다. 진단 결과에 따라 첫 수업과 교수 플랜, 첫 교재가 1/31/71/121/171/211차시에서 시작한다. 이전 단원을 이수한 것으로 기록하지 않으며 실제 수업 횟수로 과금한다. 재진단으로 기존 진도를 초기화하지 않는다.

현재 진단은 문법 중심의 초기 배정용이며 공식 TOPIK 성적이나 말하기 평가가 아니다. 한글 읽기·듣기·말하기의 별도 자동 진단은 아직 구현하지 않았다. 첫 수업에서 강사가 실제 수행을 확인해야 한다. 문항과 배정 알고리즘은 교육 전문가 검수 및 실제 학생 대상 타당도 검증이 필요하다.

검증: 단위 테스트 320개, 타입 검사 통과. 격리 DB에서 진단 전 첫 수업 차단, 진단 후 시작, 수준별 상위 단원 배정과 재진단 시 진도 유지까지 확인했다. 두 앱 프로덕션 빌드, 디자인·화이트라벨 검사 통과. 실제 API 브라우저 통합 4개 흐름도 통과했으며 학생 화면에서 20문항 응답과 결과 표시를 확인했다. 운영 배포는 별도다.

# 09 · 약관준수 · 보안 · 개인정보

> **이 문서의 레드라인을 하나라도 넘으면 사업이 끝난다.**

> 그 시점에 신규 모집이 멈춘다.

## 1. 플랫폼 약관 레드라인

### 확인된 조항 (italki)

- 제3자가 회원 계정을 통해 italki 플랫폼(강사 서비스 포함)을 이용하도록 승인하는 행위 금지
- 서비스 설명란에 제3자 교육 서비스를 광고하는 것 금지
- 경쟁 언어 서비스 홍보 금지
- 프로필·강사 신청서에 허위·오해 소지 있는 정보 기재 금지
- 교사 계정은 1개만 허용, 타인과 공유 불가
- 위반 시 즉시 계정 정지·해지, 적립 크레딧 몰수, 수업 이력 접근 상실

Preply도 유사한 외부 유도 금지 조항을 둔다.

> 약관은 수시로 개정된다. **분기 1회 재확인하고 이 문서를 갱신한다.** 담당자를 지정할 것.

### 절대 금지 (개발 레벨에서 원천 차단)

| # | 금지 행위 | 차단 방법 |
|---|---|---|
| R1 | 강사 플랫폼 계정에 대신 로그인 | 자격증명 입력 필드를 **만들지 않는다** |
| R2 | 프로필·지원서 자동 제출 | 생성물은 **복사/다운로드 전용**. 제출 버튼 없음 |
| R3 | 학생 화면에 우리 브랜드 노출 | 화이트라벨 릴리즈 게이트 (아래 2절) |
| R4 | 학생 화면에 예약·결제 기능 | 해당 라우트·컴포넌트 자체를 만들지 않음 |
| R5 | 경력·자격을 지어내는 문구 생성 | 프로필 생성기는 **입력값 재구성만**. 없는 사실 추가 금지 |
| R6 | 플랫폼 외부 수업·결제 유도 | 학생에게 강사 연락처·외부 링크 노출 금지 |

### R2 구현 규칙

```
프로필 문구 생성기 · 소개영상 스튜디오 산출물은
  · 클립보드 복사
  · 파일 다운로드
두 가지 형태로만 제공한다.

"italki에 바로 올리기" 같은 버튼은 만들지 않는다.
편해 보이지만 그 버튼이 계정 몰수를 부른다.
```

### R5 구현 규칙

```
입력: 학위·자격증·경력 연수·가르친 학생 수
출력: 그 사실을 다국어로 재구성한 문장

금지: "열정적인", "최고의" 같은 검증 불가 수식을 사실처럼 배치하는 것
금지: 입력에 없는 경력·자격을 문장에 등장시키는 것
LLM 프롬프트에 "입력에 없는 사실을 만들지 말 것"을 하드 제약으로 명시
```

## 2. 화이트라벨 릴리즈 게이트

학생 화면 배포 전 **자동 테스트로 검사**한다. 하나라도 실패하면 배포 중단.

```
□ 렌더된 HTML 전문에 서비스명 문자열 없음
□ <title> === "{강사명} 선생님의 학습 노트"
□ favicon · og:image · manifest 아이콘에 우리 로고 없음
□ 예약 관련 요소 없음 (data-testid="booking" 존재 여부)
□ 결제·충전 관련 요소 없음
□ 다른 강사 목록·검색 요소 없음
□ 외부 링크 중 우리 마케팅 페이지로 가는 것 없음
□ 도메인이 note.* 서브도메인 (메인 브랜드 도메인 아님)
```

### 학생 화면에 넣어도 되는 것 / 안 되는 것

| 허용 | 금지 |
|---|---|
| 단어장 · 오답노트 | **수업 예약** |
| 복습 퀴즈 (SRS) | **결제 · 크레딧 충전** |
| 소리 구분 훈련 (HVPT) | **다른 강사 목록 · 검색** |
| 4·3·2 유창성 | **우리 브랜드 로고 · 회사명** |
| 다청 · 진도 그래프 | 강사 개인 연락처 |
| 숙제 제출 | 외부 마케팅 링크 |

**이 선을 넘고 싶은 유혹이 반드시 온다.** "학생이 이미 우리 앱에 있는데 예약 버튼 하나만…" — 그 버튼이 사업을 끝낸다. Phase 3 정식 전환까지 참는다.

## 3. 콘텐츠 우회 방지

우회 시나리오와 차단 수단.

| # | 우회 시나리오 | 차단 |
|---|---|---|
| U1 | 자료 다운로드 후 학생 등록 없이 수업 | 다운로드·인쇄 전면 차단. student_id 없으면 403 |
| U2 | 학생 A 레코드로 B·C를 돌려씀 | 학생 이메일 인증 필수. 4차시부터 미인증 차단 |
| U3 | 화면 캡처로 슬라이드 복제 | 학생명 워터마크 **서버 합성**. 캡처해도 추적 가능 |
| U4 | 자료만 열고 실제 수업은 밖에서 | student_activity 필수 (활성 판정 B조건) |
| U5 | 결제 안 하고 계속 사용 | 미납 3일 후 자동 잠금 |
| U6 | 여러 강사가 한 계정 공유 | 동시 세션 2개 제한, 기기 지문 이상 감지 |

### U3 워터마크 구현 (중요)

```
✕ CSS 오버레이 · DOM 요소  → 개발자도구로 제거됨
○ 서버에서 이미지에 직접 합성 후 전달

합성 내용: "{학생 로마자명} · {강사명} · {YYYY-MM-DD}"
위치: 우하단, 불투명도 50~60%, 대각선 반복 패턴 병행
폰트: 배경 대비 최소, 그러나 캡처 시 판독 가능한 수준
```

### 자료 전달 규칙

```
· 정적 CDN 경로 노출 금지
· 서명 URL TTL 300초
· URL 은 student_id · teacher_id · unit_id 조합에 바인딩
· 다른 학생 컨텍스트로 같은 URL 재사용 시 403
· asset_views 에 전건 기록 (teacher_id, student_id, unit_id, ip_hash, ua_hash)
```

### U6 감지 규칙 (플래그만, 자동 제재 없음)

```
· asset_views 있으나 student_activity 30일 이상 0
· 동일 학생 레코드에서 학습 기기 지문 급변
· 30일 내 completed 처리 후 신규 등록 5건 이상 반복
· 동일 IP에서 서로 다른 강사 계정 3개 이상

→ admin/flags 에 표시. 사람이 확인한다. 자동 차단하지 않는다.
```

## 4. 개인정보 보호

### 수집 항목과 근거

| 대상 | 항목 | 목적 | 보관 |
|---|---|---|---|
| 강사 | 이메일, 이름, 연락처, 국가, 타임존, 시급 | 서비스 제공·과금 | 탈퇴 후 즉시 파기(법정 보존 제외) |
| 강사 | PG 빌링키 | 결제 | 카드 해지 시 즉시 파기 |
| 학생 | 이름, 이메일, 모국어, 국가 | 학습노트 제공 | 강사 탈퇴 후 90일 |
| 학생 | 학습 이력(단어장·SRS·HVPT) | 학습 서비스 | 상동 |

### 저장 금지 (절대)

```
✕ 학생 이메일 평문         → email_enc(AES-256-GCM) + email_hash(sha256+pepper)
✕ 수업 음성 원본           → STT 미사용. 저장하지 않음
✕ 강사 플랫폼 로그인 정보  → 수집 자체를 하지 않음
✕ 카드번호                 → PG 빌링키만
✕ 학생 결제 정보           → 우리는 학생에게 과금하지 않음
✕ 주민등록번호             → 수집하지 않음
```

### 학생 동의

```
학습노트 매직링크 최초 클릭 시 동의 화면
  · 수집 항목 · 목적 · 보관기간
  · 언어: 학생 L1
  · 동의 없이는 학습노트 이용 불가 (필수 동의)
  · 철회 요청 시 30일 내 파기, 강사에게 통지

※ 강사가 학생 이메일을 입력하는 시점에도
   "학생 동의를 받았음" 체크를 강사에게 확인받는다
```

### 국외 이전

학생이 해외 거주자이므로 GDPR 등 적용 가능성이 있다. 인프라를 국내에 두되, **EU 거주 학생 비중이 유의미해지면 법률 자문을 받는다.** 초기에는 데이터 최소 수집 원칙으로 위험을 낮춘다.

## 5. 법적 검토 필요 항목

**개발과 병행해 전문가 자문을 받아야 할 사항. 미해결 상태로 런칭하지 않는다.**

| # | 쟁점 | 왜 위험한가 | 현재 설계의 대응 |
|---|---|---|---|
| L1 | 직업안정법 유료직업소개사업 | 취업·소득에 연동한 금전 수취는 유료직업소개로 해석될 여지 | **성과 연동 수수료 전면 배제.** 학생 단위 SaaS 이용료로만 과금 |
| L2 | 전자상거래법 표시·환불 | 구독형 서비스 고지 의무 | 요금·주기·휴면·환불 정책 명시. 청구 내역 투명 공개 |
| L3 | 개인정보보호법 | 강사가 제3자(학생) 정보를 입력 | 강사 동의 확인 + 학생 본인 동의 절차 |
| L4 | 여신전문금융업법 | 자동 정기결제 | 자사 PG 활용. 변동금액 청구 근거(내역) 보관 |
| L5 | 저작권 | 다청 콘텐츠 | 외부 콘텐츠 복제 금지. 자체 제작·라이선스분만 |
| L6 | 플랫폼 약관 위반 방조 | 우리 도구가 강사 위반을 유발할 경우 | 레드라인 R1~R6 원천 차단 |

**L1이 가장 중요하다.** 이것이 30% 성과 수수료를 버리고 학생 단위 정액으로 간 법적 근거다.

## 6. 보안

### 인증

```
강사   JWT (access 30분 / refresh 30일, 회전)
       비밀번호 Argon2id, 최소 10자
       로그인 실패 10회/10분 → IP 차단
학생   매직링크만. 비밀번호 없음
       링크 TTL 15분, 1회용, 세션 쿠키 30일
       HttpOnly · Secure · SameSite=Lax
```

### 권한 검사 (모든 자원 접근 시)

```
1. 요청자가 해당 teacher_id 소유자인가
2. student.teacher_id === 요청 teacher_id 인가
3. teacher.billing_status !== 'locked' 인가
4. student.status 가 자료 열람 가능 상태인가
5. student 미인증 & lesson_no >= 4 → 거부

→ 미들웨어로 강제. 개별 핸들러에서 빠뜨릴 수 없게 한다
```

### 그 외

```
· 전 구간 HTTPS · HSTS
· CSP: script-src 'self' 지정 CDN만, unsafe-inline 금지
· DB 암호화 저장(at rest) + 백업 암호화
· 감사 로그: 자료 열람 · 과금 · 학생 삭제 · 관리자 조회 전건
· 관리자 계정 2FA 필수
· 학생 PII 는 관리자 화면에서도 마스킹 (전체 조회는 별도 권한 + 로그)
· 시크릿은 환경변수/시크릿 매니저. 코드·저장소에 절대 커밋 금지
```

## 8. 릴리즈 체크리스트 (매 배포)

```
□ 화이트라벨 자동 테스트 8항목 전부 통과
□ 자료 요청 시 student_id 누락 → 403 반환 확인
□ 미인증 4차시 → 403 반환 확인
□ 워터마크가 서버 합성으로 들어가는지 확인 (DOM 제거 불가)
□ 서명 URL TTL 300초 확인
□ 신규 외부 API 종량과금 추가 여부 확인 (있으면 반려)
□ 강사 자격증명 입력 필드 신규 추가 여부 확인 (있으면 반려)
□ 학생 화면 예약·결제 요소 추가 여부 확인 (있으면 반려)
```

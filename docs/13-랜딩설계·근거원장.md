## 0. 이 문서가 정하는 것

랜딩이 무엇을 주장하고, 그 주장을 무엇으로 받치는가.

이 제품은 "한국어를 가르치라"고 남을 설득해야 파는 물건이 아니다.
이미 가르치고 있는 사람에게 "당신 준비 시간을 0으로 만들어 주겠다"고 말하는 물건이다.
그런데 방문자가 그 말을 믿으려면 먼저 **우리가 이 시장을 아는 사람인지**를 봐야 한다.
랜딩의 역사·데이터 구간은 자랑이 아니라 그 증명이다.

**이 문서의 절대 규칙 하나**

> 화면에 오르는 모든 숫자와 인용은 §3 근거 원장에 출처와 함께 있어야 한다.
> 원장에 없으면 화면에 못 올린다. 기계가 막는다(`test/*.spec.ts`).

D-003 이 외부 **자산**에 대해 하는 일을, 이 문서는 외부 **주장**에 대해 한다.

### 왜 로마자 워드마크인가

고객은 한국어를 **가르치는** 사람이고, 그 사람의 학생은 전 세계에 있다.
italki 한국어 강사 537명(§3-D1)은 프로필이 영어로 노출되는 시장에 있다.
로마자 워드마크는 그 시장에서 읽히고, 표식은 그 이름이 어디서 왔는지를 말한다.

표식을 글꼴로 찍지 않는 이유는 06번 §0 이다 — "장식이 아니라 획으로 짓는다."
글자 자체가 획인 자리가 여기다. 어느 글자를 어떻게 떴는지는 §6 에 있다.

### 어원 표기 주의

'사맛디'의 기본형은 **'사맟다'** 다('사맛다'가 아니다).
중세국어 8종성법 때문에 표기상 '사맛디'로 적힌 것이고 어간은 '사맟-'이다.
(국립국어원 옛말사전 · 한국일보 「우리말 톺아보기」 2018-04-29)

원문은 아래아·반치음이 섞인 옛한글이라 IBM Plex Sans KR 이 못 그린다.
**옛한글 원문을 그대로 화면에 올리지 않는다** — 한글 이야기를 하는 구간에서
한글이 네모로 뜨는 것보다 나쁜 것은 없다. 현대 자모로 옮겨 쓰고, 옮긴 것임을 화면에 밝힌다.

## 2. 랜딩의 논증 구조

일곱 마디다. 순서가 논증이라 **바꾸면 결론이 안 선다.**

| # | 구간 | 바닥 | 하는 말 | 근거 |
|---|---|---|---|---|
| 1 | 히어로 | 종이 | 읽으면 되는 수업 대본을 준다 | 제품 |
| 2 | 이름의 내력 | 한지 | 580년 전에 같은 일이 있었다 | §3-A |
| 3 | 지금 벌어지는 일 | 먹 | 한류가 세계를 덮었다 | §3-B |
| 4 | **그래서 배운다** | 흰 | **그래프 2장** — 수요는 추측이 아니다 | §3-C |
| 5 | 그런데 못 가르친다 | 종이 | 강사는 537명, 교재는 강사 몫 | §3-D |
| 6 | 우리가 주는 것 | 흰 | 준비 시간 0 | 제품 |
| 7 | 가입 | 먹 | | |

### 마디 사이의 접속

각 구간의 마지막 문장이 다음 구간의 제목을 요구해야 한다. 그렇지 않으면 카탈로그가 된다.

```
2 → 3   "글자는 있는데 못 읽던 문제를 세종이 풀었다"
        → "지금은 배우려는 사람이 밖에서 밀려온다"
3 → 4   "한류 팬이 2억 2,500만 명이다"
        → "그중 얼마가 실제로 한국어를 배우기 시작했는가"   ← 그래프
4 → 5   "미국 대학에서 다른 언어는 다 줄었는데 한국어만 늘었다"
        → "그런데 그들을 맞을 강사는 537명이다"
5 → 6   "교재는 강사 몫이라고 플랫폼이 문서에 써 놓았다"
        → "그 몫을 우리가 대신 진다"
```

### 마디 4가 이 랜딩의 심장인 이유

2·3번은 누구나 아는 이야기다("한글 대단하다", "한류 크다").
아는 이야기는 설득하지 못한다. 4번만이 방문자가 **모르던 것**을 준다 —
"미국 대학에서 스페인어가 18% 줄어드는 동안 한국어는 38% 늘었다"는
한국어 강사조차 대부분 모른다. 그래프는 여기 놓는다.

| 강조 | 2019 최고 · 2020 코로나 · 2024 신기록 | **한국어만 jade, 나머지 honghwa** |

### 4.2 색 — 검증한 값만 쓴다

06번 §1 의 `--jade` `--honghwa` 는 **차트 마크로 쓰면 검사에 걸린다.**
`#1E7A5F` 는 채도 0.094 로 채도 하한(0.1) 미달이라 작은 막대에서 회색으로 읽힌다.

그래서 차트 전용 계단을 하나씩 더한다. UI 의 상태색은 그대로 두고, 차트에서만 이 값을 쓴다.

```css
--jade-chart:    #1A8A68;   /* 증가 */
--honghwa-chart: #C4372A;   /* 감소 */
```

검증 결과 (`dataviz/scripts/validate_palette.js`, light, surface #FCFCFB):

```
[PASS] Lightness band      둘 다 L 0.43–0.77
[PASS] Chroma floor        둘 다 ≥ 0.1
[PASS] CVD separation      ΔE 8.4 (deutan) · 32.2 (tritan)
[PASS] Normal-vision floor ΔE 27.1
[PASS] Contrast vs surface 둘 다 ≥ 3:1
```

CVD ΔE 8.4 는 8–16 구간이므로 **2차 부호화가 의무다** — 그래서 모든 막대에
부호(`+`/`−`)와 수치를 직접 라벨로 붙인다. 색만으로 증감을 말하지 않는다(06번 §1·§7).

### 4.3 마크 규격

```
막대 끝 라운드 4px · 기준선에 앵커
막대 사이 2px 표면 간격
축·격자는 후퇴 (rule-soft 1px, 격자 최소)
숫자는 전부 mono (06번 §2 절대 규칙)
직접 라벨은 선택적으로 — 모든 점에 숫자를 붙이지 않는다
결측 연도는 자리를 비우고 캡션에 밝힌다
```

### 4.4 접근성

- 서버 컴포넌트로 그린다. **랜딩에 클라이언트 JS 를 늘리지 않는다**(06번 §6: 페이지 모션 금지).
  따라서 호버 툴팁은 두지 않고, 그 대신 **표 보기를 반드시 제공한다.**
- `<details>` 로 원본 수치 표를 접어 둔다. 네이티브 HTML 이라 JS 가 필요 없다.
- SVG 에 `role="img"` + `aria-label` (06번 §7).
- 색 + 부호 + 수치 3중 표기.

**한류 콘텐츠의 실사 이미지(스틸·포스터·공연 사진·로고)를 쓰지 않는다.

유료 SaaS 랜딩은 정의상 promotional 이다. editorial 라이선스가 금지하는 바로 그 용도다.

### 그러면 무엇을 놓는가

1. **사실 진술.** 이름과 숫자는 출처를 달면 쓸 수 있다 — 사실 진술은 복제가 아니다(08번 §6).
2. **오리지널 그래픽.** 자모 상형 표, 그래프, 획으로 그린 도형. 남의 저작물이 아니고,
   06번 §0 의 "획으로 짓는다"와 맞고, 무엇보다 **경쟁자가 복사할 수 없다.**
3. **특정되지 않는 사진.** 어느 공연인지 알 수 없는 객석 사진(`hallyu-lightsticks`).
   **캡션에 가수 이름을 붙이는 순간 위반이 된다.**

### 나중에 실사를 쓰기로 한다면

이 판단을 뒤집으려면 아래가 **전부** 있어야 한다. 하나라도 없으면 뒤집지 않는다.

```
□ 넷플릭스/하이브와의 서면 라이선스 계약서
□ 그 계약이 "제3자 유료 SaaS 의 마케팅 페이지" 용도를 명시적으로 포함
□ 출연자 초상권에 대한 별도 처리(퍼블리시티권은 저작권과 다른 권리다)
□ licenses.ts 의 hallyu-ip-imagery 항목을 blocked → 허용으로 바꾸고 계약 근거 기록
```

판단 기록은 D-003 규칙대로 레지스트리(`licenses.ts` 의 `hallyu-ip-imagery`)에 남긴다.

## 6. 표식 — 원문에서 글자를 뗀다

**워드마크** 로마자 `SAMAT` · **표식** 훈민정음 해례본의 `通`

### 왜 通 인가

이름이 나온 문장에 그 글자가 들어 있다.

```
서르 ᄉᆞᄆᆞᆺ디 아니ᄒᆞᆯᄊᆡ      언해본
不相流通                      한문 원문
       ↑ 여기
```

'사맟다 = 통하다' 이므로 SAMAT 의 뜻이 通 이다.
표식이 이름을 그림으로 옮긴 것이 아니라 **이름이 나온 문장에서 글자를 그대로 뗀 것**이다.

한글을 파는 회사가 한자를 표식으로 쓰는 것이 앞뒤가 안 맞아 보이는데,
이 글자가 나오는 문장이 바로 「한자로는 서로 통하지 아니한다」 이다.
통하지 않는다고 적힌 자리에서 通 을 떼어 와 "우리가 통하게 한다" 로 쓴다.

> 다른 글자로 바꾸면 출처가 끊긴다. 이 표식의 값은 글자 모양이 아니라
> 그 글자가 어디서 왔는지에 있다.

### 원본과 라이선스

| | |
|---|---|
| 스캔 | `Hunminjeongeum_Haerye_02.jpg` (1920×1280) |
| 소장 | 서울대학교 규장각한국학연구원 |
| 라이선스 | `PD-1923` · `PD-South Korea` |

원 저작물(1446)은 저작권이 소멸했고, 평면 저작물을 그대로 찍은 복제물에는
새 저작권이 생기지 않는다.

**같은 문서라도 촬영물마다 다르다.** 국립한글박물관 전시 사진(5312×2988)은
해상도가 훨씬 좋지만 CC BY-SA 4.0 이라 파생물에 라이선스가 전염된다. 안 쓴다.

### 벡터화 — 왜 이미지가 아닌가

원본에서 通 이 차지하는 넓이는 **74×72px** 뿐이다. PNG 로 쓰면 2배 화면에서
뭉개지고, 먹 바닥에서 흰색으로 뒤집을 수 없고, 파비콘 크기에서 죽는다.

```
확대(10배, LANCZOS) → 종이 결 제거(bilateral) → Otsu 이진화
→ 모폴로지 정리 → 티끌 제거 → 윤곽 추출(RETR_CCOMP) → 폴리곤 단순화
```

`RETR_CCOMP` 로 계층을 살린다 — 用 안쪽 가로획 사이가 구멍이라
`fill-rule="evenodd"` 로 칠해야 한다. `nonzero` 면 검은 덩어리가 된다.

단순화 정도를 셋 비교했다.

| eps | 패스 크기 | 판단 |
|---|---|---|
| 0.0012 | 8.9KB | 종이 결의 흔적까지 남는다 |
| **0.0025** | **4.3KB** | **채택** |
| 0.004 | 2.4KB | 목판의 삐뚤함이 사라져 명조체 通 처럼 보인다 |

그 삐뚤함이 이 표식의 전부라서 0.0025 에서 멈췄다.
`currentColor` 로 칠하므로 먹 구간에서 부모가 흰색을 주면 흰 글자가 된다.

### 크기별 사용

| 자리 | 크기 | 비고 |
|---|---|---|
| Shell · 로그인 | 19px | 내부 획이 뭉치지만 마크로는 성립 |
| 랜딩 헤더 | 22px | 읽히는 최소선 |
| 히어로 · 푸터 · og:image | 40px+ | 목판 질감이 살아난다 |

24px 아래에서는 광곽(테두리)을 두르지 않는다 — 테두리가 글자 자리를 먹는다.

### 서문 이미지 — 앞선 판단을 뒤집었다

`photos.ts` 에 "해례본 사진은 소장 기관 촬영물이라 쓸 수 없다" 고 적고
Pexels 의 일반 한문 문서 사진을 대역으로 썼었다. 확인해 보니 틀렸다.
PD 스캔이 있어서 **진짜 문서**로 바꿨다.

원본 그대로가 아니라 누끼다. 종이와 장서인을 지우고 먹만 남겼다 —
그래야 한지 바닥에 얹었을 때 사진이 아니라 글이 된다.
그래서 `PhotoFrame` 을 쓰지 않는다. 테두리와 바탕색을 두르면 액자에 든 사진이 되고,
`aspect` 로 자르면 문서가 잘린다.

알파에 계조를 남긴다. 이진화하면 획 끝의 갈필이 사라져 폰트처럼 보인다.

장서인 제거에 함정이 하나 있었다. 붉다는 이유만으로 지우면 도장 아래 글자까지
파인다 — 우하단 「與文字」 의 字 가 실제로 그렇게 됐었다.
**붉고, 그러면서 먹만큼 진하지 않은** 화소만 지워야 한다.

재현 절차와 좌표는 `tools/mark/README.md` 에 있다.

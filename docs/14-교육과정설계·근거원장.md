## 0. 이 문서가 하는 일

13번 문서가 랜딩의 주장에 근거를 붙였다면, 이 문서는 **교재의 주장**에 근거를 붙인다.

교재는 랜딩보다 위험하다. 랜딩의 과장은 안 읽히고 끝나지만, 교재의 틀린 설명은
**강사 앞에서 학생이 질문할 때 드러난다.** 그 강사는 다시 오지 않는다.

그래서 같은 규칙을 쓴다.

> 08번 §0 이 이미 정했다 — **"마케팅에는 '검증' 등급만 쓴다."**
> 이 문서는 그 규칙을 교재 본문까지 넓힌다.
> 등급이 안 붙은 교육적 주장은 교재에 못 들어간다.

## 2. 5단계 재편

기초 · 초급 · 중급 · 심화 · 프리토킹.

| 단계 | TOPIK | 차시 | 어휘 누적 | 현재 |
|---|---|---|---|---|
| **도입** | — | **1** | — | ❌ 0 |
| 기초 | 1급 | 2~25 | ~800 | ✅ 뼈대 있음 |
| 초급 | 2급 | 26~50 | ~1,835 | ✅ 뼈대 있음 |
| 중급 | 3~4급 | 51~85 | 5,690 | ❌ 0 |
| 심화 | 5~6급 | 86~100 | 10,635 | ❌ 0 |
| 프리토킹 | 병행 | 별도 트랙 | | ❌ 0 |

100차시는 6급까지 가기엔 빠듯하다. 심화 15차시로 5~6급을 끝낼 수 없다 —
이건 "100차시로 6급 완성"이 아니라 **"100차시로 4급 + 심화 맛보기"** 라고
정직하게 표기해야 한다. 6급까지 원하면 차시가 더 필요하다.

### 도입 1차시 — 한글보다 먼저 오는 것

**한글부터 가르치지 않는다.** 학습자가 "이 언어가 어떻게 생겼는지" 모르는 채로
자모를 외우면 그게 무엇을 위한 것인지 모른다.

| | 내용 | 한글 |
|---|---|---|
| 체험 30분 (무료·기존) | 목적 파악 → **트랙 배정** · 이름 써 보기 | 맛보기 |
| **1차시 · 한국어 지도** | 어순이 다르다(SOV) · 조사가 있다 · 높임말이 있다 · 성조는 없다 · 내 모어와 무엇이 다른가 · 앞으로 어디까지 가는가 | **안 함** |
| 2~4차시 · 한글 | 모음 → 자음 → 받침 | |

근거: 초기 이탈이 가장 큰 위험이다(언어앱 8주 **26.3%**, MOOC **78~90%**).
기대 설정이 그것을 막는 지점이고, "무엇을 배우는지 모른 채 외우기"가 이탈의 전형이다.

부수 효과로 §3.6 의 「한글 1시간 완성」 문제가 같이 풀린다 —
한글을 **3차시에 나눠** 배치하면 없는 성과를 약속하지 않아도 된다.

### 목적별 분기 — 체험에서 끊긴 것을 잇는다

`trial-packs.ts` 에 이미 4트랙이 있다: `kcontent · travel · eps · topik`.
체험 3~8분이 "학생 목적 파악"이다. **그런데 거기서 끊긴다** —
목적을 파악해 놓고 정규 커리큘럼은 전원에게 같은 것을 준다.

**분기 방식에 근거가 있다.** 이안나(2010)에서 일본어권·중국어권 간
조사 습득 순서에 유의미한 차이가 없었다. 문법 뼈대는 공통으로 가도 된다.
갈라야 하는 것은 어휘·예문·상황이다.

```
차시 = 공통 문법 뼈대 (100차시 · 습득 순서는 목적·모어와 무관)
     × L1 변이   (모어별 — 조사 구간 길이, 발음 우선순위)   ← 08번 §1 에 이미 있음
     × 목적 변이 (관심사별 — 어휘, 예문, 롤플레이 상황)     ← 새로 추가
```

4트랙 × 100차시 = 400개를 만드는 것이 아니다. **뼈대 100 + 트랙별 교체분**이다.
그렇지 않으면 물리적으로 불가능하다.

트랙 목록과 그 순위는 §2.5 에 근거와 함께 있다.

| 트랙 | 어휘·상황이 향하는 곳 |
|---|---|
| `kcontent` | 가사·대사에 나오는 표현, 팬 커뮤니티 말 |
| `travel` | 주문·길찾기·숙소·응급 |
| `eps` | 작업장 지시, 안전, 임금·계약 |
| `topik` | 시험 문형, 답안 쓰기 |

같은 12차시(을/를)라도 kcontent 는 가사 문장으로, eps 는 작업 지시문으로 드릴한다.
**문법은 같고 입력이 다르다.**

### 프리토킹은 레벨이 아니라 형식이다

앞의 넷은 문법 순서로 쌓인다. 프리토킹은 그렇게 못 만든다.
**같은 방식으로 100차시를 더 만드는 것이 아니라 다른 물건을 만드는 것이다.**
필요한 자산이 다르다 — §5 에 따로 적었다.

병행 트랙으로 두는 이유: 초급을 마친 학습자도 프리토킹을 원하고,
중급 학습자도 문법 차시와 번갈아 쓴다. 레벨에 묶으면 그 수요를 못 받는다.

## 2.5 학습 동기 — 트랙의 순위는 여기서 나온다

트랙을 무엇으로 나눌지는 **학습자가 왜 배우는가**로 정한다.
우리가 무엇을 잘 만들 수 있는지는 순위에 넣지 않는다 — 그건 §6 제작 순서의 문제다.
둘을 섞으면 수요가 작은 칸을 크다고 착각하게 된다.

### 조사에서 나온 것과 안 나온 것

**안 나온 것을 먼저 적는다.** 「한국어 학습자 중 몇 %가 한류 때문인가」를
수치로 답한 자료는 **존재하지 않는다.** 듀오링고 5개 연도 보고서 · TOPIK 통계 ·
세종학당 · KOFICE 어디에도 없다.

유일하게 수치화된 문화 동기는 **일본어**의 것이다 —
2021 듀오링고: 신규 일본어 학습자의 18%가 문화 동기(영어 8% · 스페인어 9% · 프랑스어 10%).
**이것을 한국어 수치로 옮겨 쓰지 않는다.**

> 그러므로 교재·랜딩 어디에도 "K-pop 때문에 배우는 사람이 N%" 라고 쓸 수 없다.
> 13번 §3-C 의 인과 서술 금지 규칙이 여기에도 적용된다.

**우리 고객(1:1 유료 수강생)** 기준으로는 그 격차가 줄어든다.
이 보정을 뒷받침할 자료는 못 찾았다 — 강사 플랫폼의 학습자 동기 통계는 공개돼 있지 않다.

### 1위 안에서 — 한류 어느 분야인가

| | 분야 | KOFICE 15차 (30개국 27,400명) | 한국어로 이어지는 경로 |
|---|---|---|---|
| 1 | **K-pop** | 연상 이미지 1위 **17.5%**(9년 연속) · 인기도 2위 54.0% | **강함** — 가사가 한국어 |
| 2 | **드라마·영화** | 경험률 2·3위(77.9% / 72.9%) · **미국 +10%p** | **강함** — 대사가 한국어 |
| 3 | 음식 | **경험률 1위 78.0% · 인기도 1위 55.1%** | 약함 |
| 4 | 뷰티 | 인기도 3위 52.6% · 지출 2위 | 약함 |
| 5 | 패션 | **지출 1위 33.9 USD** | 약함 |
| 6 | 웹툰 | 인기도 32.2% | 강함 — 텍스트 매체 |
| 7 | 게임 | 수출 85억 달러 | 중간 — 채팅 |

**음식이 관심 1위인데 3위로 내린 이유** — 김치를 좋아하는 것과 한국어를 배우는 것
사이의 경로가 약하다. K-pop · 드라마 · 웹툰은 **콘텐츠 자체가 한국어**라서
"더 알아듣고 싶다 → 배운다"가 성립한다.

> **이 판단에는 근거가 없다.** 분야별 관심이 언어 학습으로 전환되는 비율을
> 측정한 자료를 찾지 못했다. `[미확인]` 으로 표시하고, 반증이 나오면 순위를 바꾼다.

### 3.1 마스터 출처 — 이것 하나가 커리큘럼의 뼈대다

| | |
|---|---|
| 자료 | 국립국어원 「국제 통용 한국어 표준 교육과정 적용 연구(4단계)」 (2017, 김중섭 외) |
| URL | https://www.korean.go.kr/front/reportData/reportDataView.do?mn_id=45&report_seq=932 |
| 내용 | 급별 어휘·문법 목록 엑셀 |
| 등급 | `[검증]` — 정부 기관 공식 발간, 학계·교재 개발의 사실상 표준 |

```
3급  어휘 1,655 · 문법 67항목
4급  어휘 2,200 · 문법 67항목
1~4급 누적 어휘 5,690
전체(6급) 누적 어휘 10,635 · 문법 336항목
```

> **미해결 — 규모가 안 맞을 수 있다.**
> 문법 336항목을 200차시에 넣으면 차시당 1.7개다. 그런데 §3.3 의 Schenck & Choi 는
> **한 처치에 개념 하나**일 때 효과가 최대고 여러 개를 몰아넣으면 역효과라고 한다.
> 336항목 중 이형태·유사형이 얼마나 묶이는지는 **실제 엑셀을 받아야 확정된다.**
> 이것이 이 설계의 첫 번째 행동 항목이다.

### 3.2 기초 — 한글과 입문

| | 사실 | 등급 | 조치 |
|---|---|---|---|
| A1 | **"한글 1시간 완성"은 학술 근거가 없다.** 출처는 대중서 *Learn Hangul in One Hour* 이고, Pae(2024) *Analyzing the Korean Alphabet* (Springer)가 그 사실을 지적한다. 성인 습득 시간을 측정한 통제 실험은 없다 | `[관행→배제]` | **1차시 제목을 바꾼다** |
| A2 | 자모 제시 순서(가나다/조음위치/빈도)의 우열을 비교한 실험이 없다 | `[미확인]` | 저자 판단임을 명시 |
| A3 | 상형원리 교육이 습득을 돕는다는 근거가 없고 **반론이 있다** — DeFrancis(1989), Taylor&Taylor(2014): 대부분의 해득자는 제자원리를 활용하지 않는다 | `[반론 존재]` | 랜딩의 역사 서술은 유지. **교재에서 "효과적 학습법"으로 포장 금지** |
| A4 | 로마자 병기가 한글 습득을 늦춘다는 **한국어 직접 증거가 없다.** 최근접 근거는 일본어 로마지 연구 — Okuyama(2007): 로마지가 어휘 습득을 촉진하지 않음 | `[연구근거·유추]` | 원칙은 유지, "검증됐다"고 쓰지 말 것 |
| A5 | 받침 도입 시점("초성·중성 먼저")을 비교한 실험이 없다 | `[관행]` | 실증으로 포장 금지 |
| A6 | HVPT 가 한국어 평음·경음·격음 삼중대립에 효과 — Lee & Park(2025) *Phonetics and Speech Sciences* 17(3): 3일 훈련, 격음 인식 **94.2% vs 79.8%**, 새 화자 일반화·1주 후 유지 | `[검증]` | 발음 단원에 반영. **n=10 소표본·영어권 한정** 명시 |

## 4. 차시 설계 원칙 (근거가 바꾼 것)

08번 §2 의 50분 틀은 유지하되, 아래를 덮어쓴다.

```
1. 차시당 문법 1개                          ← B1 (개념 수 ↑ → 효과 ↓, 역효과 구간 존재)
2. 명시적 설명을 없애지 않는다               ← B2 (g=1.06)
3. 복습은 다음 차시가 아니라 여러 차시 뒤     ← B6 (긴 간격이 지연회상에 유리)
4. 드릴을 배제하지 않는다                    ← B7 (단순 형태소엔 드릴이 우수)
5. 은/는–이/가는 전 단계에 재출현             ← B3 (고급까지 오류율 안 떨어짐)
6. 즉각 교정 기본, 존댓말은 명시적 유도       ← D1·D2·D4
7. 다독을 정규 구성요소로                    ← C2 (d=0.57~0.79)
```

`recycleFrom` 필드가 이미 있으므로 5번은 데이터로 강제할 수 있다.
**검사로 막는다** — 은/는·이/가가 일정 간격마다 재출현하지 않으면 테스트 실패.

## 5. 프리토킹 트랙 설계

문법 차시와 **다른 물건**이다. 강사의 부담이 자료가 아니라 **판단**이기 때문이다.

### 50분 진행표 (강사가 결정할 것을 남기지 않는다)

```
0–3    워밍업
3–5    사전 계획 — 학습자가 말할 것을 메모      ← 검증된 기법
5–14   4/3/2 반복 발화                        ← 유창성 향상 확인
14–39  주제 토론 (참조적 질문 + 대기 3초 규칙)
39–47  교정 리뷰
47–50  마무리
```

### 자산 목록

| 자산 | 근거 |
|---|---|
| 주제 카드 (발산형·친숙도별 분류) | Qiu(2020), Aksoy-Pekacar(2023) — 친숙·발산형일수록 발화량↑ |
| 4/3/2 진행 대본 (타이머 내장) | dos Santos & Ramírez-Ávila(2022), Tran & Saito(2024) |
| 사전 계획 워크시트 | Tabari(2024), Gu & Van den Branden(2026) |
| 참조적 질문 뱅크 | Kosar(2024) — 교사가 답을 모르는 질문이 STT 를 늘림 |
| 대기 시간 카드 ("3초") | Kamdideh & Barjesteh(2019) |
| 교정 기록 시트 | D1~D4 — **즉각 교정 기본**, 존댓말은 prompt |
| 그날의 토론 패키지 | BreakingNewsEnglish 모델 |

### 유창성 훈련의 한계를 지도서에 적는다

4/3/2 는 **유창성(속도·망설임)** 을 개선하지만 **정확성 개선은 제한적**이다.
Nation(1989) 본인이 "not impressive" 라고 썼다(n=6, 통제집단 없음).
de Jong & Perfetti(2011)가 통제실험으로 절차화 효과를 확인했다.
→ 유창성 훈련과 정확성 피드백을 **별도 활동으로** 설계한다.

### 경쟁 지형

- **Cambly** — 자격증·학위·경력 불필요, 시간당 $10.20. 커리큘럼 없이 강사가 즉흥 진행.
- **BreakingNewsEnglish** — 토론 세트 3,657개를 **전부 무료** 배포(영어).

→ 영어 시장엔 자료가 이미 무료로 넘친다. 우리 차별점은 자료가 아니라
**판단을 대신하는 것**이다. 위 진행표가 그것이다.

## 6. 만드는 순서

**얕은 200차시보다 완성된 30차시가 팔린다.**
강사는 30차시를 써 보고 나머지를 기다릴 수 있지만, 200차시가 다 얕으면 첫 차시에서 떠난다.

```
0  국립국어원 표준 교육과정 엑셀 확보          ← 이것 없이는 3급 이상을 못 짠다
1  08번 문서 수정 (§3.6 의 5개 항목)
2  도입 1차시 + 한글 3차시                   ← 지금 없는 구간. 여기서 이탈이 갈린다
3  기초 나머지를 완성본으로              슬라이드 20장 · 대본 풀분량 · 검수 통과
4  목적 변이 데이터 구조 + kcontent 트랙   ← 4트랙 중 가장 수요가 큰 것 하나만 먼저
5  초급 25차시
6  프리토킹 트랙 1차분 (주제 20개)        ← 문법 진도와 무관하게 바로 팔 수 있다
7  중급 35차시 → 8  심화 15차시
```

2번을 앞에 둔 이유: 도입 차시가 없어서 지금 커리큘럼은 1차시가 곧바로 한글이다.
이탈이 가장 큰 위험인데 그 위험이 첫 차시에 몰려 있다.

4번에서 트랙 하나만 먼저 하는 이유: 네 트랙을 동시에 벌리면 넷 다 얕아진다.
`kcontent` 를 먼저 하는 것은 13번 §3-C 의 수요 근거가 그쪽을 가리키기 때문이다.

4번을 앞에 둔 이유: 프리토킹은 문법 진도에 안 묶여서 **먼저 완성되면 먼저 팔린다.**

## 7. 게이트

13번 §7 이 랜딩 주장에 하는 일을 교재 주장에 대해서도 한다.

```
□ 교재·지도서의 교육적 주장에 근거 등급이 붙어 있다
□ [관행]·[미확인] 항목을 "연구로 증명된" 으로 쓰지 않는다
□ 아래 네 가지에 "검증" 표기를 붙이지 않는다 (조사에서 근거 미확인)
    · 한자어 형태소 교육의 어휘확장 효과
    · 중국어·일본어권의 한자어 전이 이점
    · 한국어 특정 "중급 정체기" 개입 효과
    · 95%/98% 커버리지 임계치의 한국어 적용
□ 차시당 문법 항목이 1개를 넘지 않는다
□ 은/는·이/가가 전 단계에 재출현한다 (recycleFrom 검사)
□ 미검수 차시가 강사에게 노출되지 않는다
```

마지막 항목이 제일 중요하다. 지금 70차시가 전부 미검수인데 화면에는 그 표시가 없다.

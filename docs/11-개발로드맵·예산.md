# 11 · 개발 로드맵 · 예산

## 0. 원칙

```
① 콘텐츠보다 잠금장치가 먼저다
   콘텐츠가 좋아도 잠금이 없으면 첫 달에 다 퍼진다.
   잠금이 좋으면 콘텐츠가 조금 부족해도 사업은 돌아간다.

② Phase 0에서 숫자를 만들지 못하면 Phase 1로 넘어가지 않는다
   이 문서 전체가 "실력이 는다"는 가정 위에 서 있다. 먼저 증명한다.

③ 기생 구조는 목적지가 아니라 진입로다
   Phase 3를 막연한 미래가 아니라 12~18개월 내 실행 항목으로 고정한다.
```

## Phase 0 — 검증 (8주 · 개발 0줄)

**목적: 숫자 하나를 만든다.**

### 트랙 A · 강사 온보딩 실증 (4주)

```
강사 20명을 무료로 붙여 실제로 italki·Preply 승인까지 통과시킨다.
도구: 노션 + 구글독스 + 줌. 코드 없음.

측정
  · italki 승인률 / 소요일수
  · Preply 승인률 / 소요일수
  · 소개영상 단계 이탈률
  · 한국어교원 자격증이 Professional Teacher 증빙으로 인정되는지  ★
```

★ 이 답이 세일즈 문구를 결정한다.
- 인정 → "자격증 있으면 프로 교사, 단가 2배" (양성기관 제휴의 결정적 무기)
- 불인정 → 전원 커뮤니티 튜터로 시작. 단가 전략 재수립

### 트랙 B · 학습 효과 A/B (12주, 트랙 A와 병행)

```
학생 20명
  A그룹 10명: 수업만
  B그룹 10명: 수업 + 도구(수기 운영)

측정
  · TOPIK 모의 점수 변화
  · HVPT 지각 점수 사전/사후
  · 수업 중 학생 발화 비율
  · 12주 잔존율
```

### 트랙 C · 콘텐츠 착수 (병행)

체험수업 팩 4종 + 한글 1시간 팩. 한국어교원 파트타임 1명 채용.

### Phase 0 게이트 (통과 못 하면 중단 또는 재설계)

```
□ italki 승인률 70% 이상, 평균 소요 15일 이내
□ B그룹 TOPIK 향상이 A그룹 대비 유의미
□ B그룹 12주 잔존율이 A그룹보다 20%p 이상 높음
□ 강사 20명 중 12명 이상이 "유료라도 쓰겠다" 응답
```

**비용: 약 1,200만원** (콘텐츠 인력 2개월 400만 + 파일럿 운영 300만 + 예비 500만)

## Phase 1 — MVP (12주)

### 스프린트 (2주 단위)

| SP | 산출물 |
|---|---|
| **S1** | 인프라 · 인증 · DB 스키마 · 강사 가입/프로필/시급 |
| **S2** | **학생 레코드 CRUD · 이메일 인증 · 중복 병합** (P0 코어) |
| **S3** | **슬라이드 뷰어 · 워터마크 서버 합성 · 서명 URL · 열람 로그** (P0) |
| **S4** | **과금 엔진** — 주기·활성판정·휴면·합산청구·잠금 + TC 14개 |
| **S5** | 수업 플로우 4단계 · 3분 리포트 · SRS 적립 |
| **S6** | 학생 학습노트 홈 · SRS · 진도 + **화이트라벨 게이트** |
| **S7** | PG 결제 연동 · 청구 화면 · 크레딧 충전 |
| **S8** | 디자인 시스템 적용 · 반응형 · 접근성 · 관리자 최소 · QA |

### 병행 (콘텐츠)

```
S1–S4  초급 1~15차시
S5–S8  초급 16~30차시 + 교실영어 250문장
```

### 출시 기준

```
□ 과금 TC-01~14 전부 통과
□ 화이트라벨 8항목 통과
□ 자료 우회 경로 없음 (student_id 없이 열람 불가)
□ 초급 30차시 + 체험팩 4종 완성
□ 강사 30명 온보딩 완료
```

**목표: 3개월 차 활성 학생 150명 · 월 매출 250만원**

## Phase 3 — 전환 (12~18개월)

```
· 우리 채널로 학생 직접 확보 (랜딩·유튜브·틱톡·현지 유학원 제휴)
· 우리가 보낸 학생만 30~40% 수수료 → 결제를 우리가 잡으므로 회수율 100%
· 확보한 강사 풀 + 학습 데이터로 자체 플랫폼 개설
· italki 학생은 절대 건드리지 않는다 (약관 위반 아님을 유지)
```

**수수료율을 올리는 길은 요금 인상이 아니라 학생 확보다.**
요금을 20%로 올리면 강사가 빠져나가 총액이 줄어든다.

## 예산

| 항목 | Phase 0 (2개월) | Phase 1 (3개월) | Phase 2 (4개월) |
|---|---|---|---|
| 개발 인건비 | — | 4,500만 | 6,000만 |
| 디자인 | — | 1,500만 | 1,600만 |
| 한국어교원 | 400만 | 540만 | 800만 |
| 인프라 | 10만 | 60만 | 200만 |
| 음원 제작 | — | 300만 | 500만 |
| 파일럿·운영 | 300만 | 300만 | 600만 |
| 법률 자문 | 300만 | 200만 | 200만 |

**누적 약 2억 100만원.** 외주 없이 소규모 팀으로 가면 60~70% 수준까지 낮출 수 있다.

법률 자문 예산을 Phase 0에 배정한 것은 **직업안정법 쟁점(09번 L1)을 런칭 전에 해소해야 하기 때문**이다.

## 손익

```
월 고정비 (Phase 2 이후 안정기)
  인건비 4명    1,800만
  콘텐츠 인력     200만
  인프라·툴        80만
  운영·마케팅     400만
  ─────────────────────
  합계          2,480만

손익분기 활성 학생 = 2,480만 / 16,500원 ≈ 1,500명
                    (강사 300명 × 학생 5명)

안정기 목표 2,000명 → 월 3,300만 → 영업이익 약 820만
```

여기에 선충전 float 상시 3,600만원이 별도로 쌓인다.

## 핵심 지표 (주간 점검)

| 지표 | 의미 | 경고선 |
|---|---|---|
| 등록 → 2차시 전환율 | 첫 과금 도달률 | 60% 미만 |
| 2차시 → 6차시 잔존율 | 학생이 붙는가 | 50% 미만 |
| 강사당 평균 활성 학생 | 매출 배수 | 3명 미만 |
| 휴면 전환율 | 주기 종료 대비 waived | 30% 초과 |
| 결제 성공률 | 회수 건전성 | 93% 미만 |
| **열람은 있으나 학생활동 0** | **우회 신호** | 10% 초과 |
| 강사 90일 잔존율 | 제품 만족도 | 60% 미만 |

마지막에서 두 번째가 가장 중요하다. **이 수치가 올라가면 잠금장치가 새고 있다는 뜻이다.**

## 착수 순서 (내일부터)

```
1주차  한국어교원 채용 공고 · 법률 자문 접수 · 강사 20명 모집 시작
2주차  체험수업 팩 4종 착수 · 파일럿 학생 20명 모집
3주차  italki 창구 모니터 구축 (반나절) → 리드 수집 개시
4주차  개발 인력 채용 · 트랙 A 온보딩 시작
```

**3주차 항목을 미루지 마라.** 반나절 작업으로 Phase 1 내내 쓸 강사 리드가 쌓인다.

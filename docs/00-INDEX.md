## 한 장 요약

### 무엇을 만드는가

italki·Preply에서 한국어를 가르치는 강사를 위한 **수업 운영 + 학생 학습 시스템**.
자체 마켓플레이스가 아니다. 기존 플랫폼 **위에 얹는 레이어**다.

### 세 주체

```
강사 → 온보딩·트레이닝·250차시 커리큘럼·수업 도구를 무료로 받음
       활성 학생 1명당 28일마다 요금 지불 (실효 부담률 약 12%)

학생 → 추가 비용 0원
       매일 19분 학습 도구 (HVPT · SRS · 4·3·2 · 다청)
       주 1회 50분 → 주 2시간 40분으로 학습시간 2.4배

우리 → 학생 단위 반복 매출 + 선충전 float + 학습 성과 데이터
       Phase 3 자체 플랫폼 전환의 자산
```

### 수익 구조 요약

| 항목 | 값 |
|---|---|
| 과금 단위 | 활성 학생 1명 / 28일 |
| 요금 | 7,900 / 14,900 / 24,900 / 39,900원 (강사 시급 구간별) |
| 실효 부담률 | 전 구간 학생 결제액의 약 12% |
| 볼륨 할인 | 활성 학생 11명 이상 20% 차감 |
| 첫 과금 시점 | 2차시 진입 시 (등록·1차시 무료) |
| 휴면 | 28일간 수업 0회 → 자동 휴면, 청구 없음 |
| 청구 방식 | 학생별 주기로 계산, 카드는 월 1회 합산 |

### 절대 넘으면 안 되는 선

1. 우리가 강사 플랫폼 계정에 로그인하지 않는다
2. 학생 화면에 우리 브랜드·예약·결제를 노출하지 않는다
3. 수업 자료를 다운로드 가능하게 만들지 않는다
4. 종량과금(STT·LLM·TTS)이 학생 수에 비례해 늘어나지 않는다

상세는 09번 문서.

### 개발 우선순위 (변경 금지)

```
P0  학생 레코드 + 차시 추적 + 과금 트리거      ← 없으면 매출 0
P0  슬라이드 뷰어 (다운로드 차단 · 워터마크)   ← 우회 방지
P0  학생 학습페이지 + 이메일 인증              ← 자물쇠 본체
P1  결제 · 크레딧 충전
P1  SRS · HVPT · 4·3·2
P2  콘텐츠 (체험팩 → 한글팩 → 초급 30차시)
P3  온보딩 스튜디오 · 창구 모니터
```

콘텐츠보다 잠금장치가 먼저다. 콘텐츠가 좋아도 잠금이 없으면 첫 달에 다 퍼진다.

## 1. 커리큘럼 구조

```
총 250차시 · 각 50분 완결 · TOPIK 1~6급 정렬

Lv.1  TOPIK 1급    1~30차시     한글 + 기본 문형 + 생존 회화
Lv.2  TOPIK 2급    31~70차시    과거/미래, 일상 대화
Lv.3  TOPIK 3급    71~120차시   연결어미 확장, 의견 표현
Lv.4  TOPIK 4급    121~170차시  추상 주제, 뉴스 이해
Lv.5~6 TOPIK 5·6급 171~250차시  전문 · 학술
```

### 1급 30차시 문법 배열 (확정)

```
01     한글 1시간 완성                      ← 로마자 사용 금지
02-04  이에요/예요 · 있어요/없어요
05-08  -아/어요 (설명 30초, 반복 9분)
09-11  이/가                               ← 주격 먼저 (습득 순서)
12-14  을/를                               ← 목적격 나중
15-17  에 · 에서 · 도 · 만
18-19  안 / 못
20-22  -았/었어요
23-24  숫자 2종(하나·일) + 조수사
25-26  의문사 6개 (뭐/누구/어디/언제/왜/어떻게)
27-28  -고 싶어요 · -(으)ㄹ 거예요
29     -(으)세요
30     존댓말 · 반말 구분
```

**은/는의 대조 용법은 1급에 넣지 않는다.** 화제-대조 오류율이 39%를 넘으므로 조기 도입은 실패한다. 2급 후반 이후로 미룬다.

### 모국어별 분기 (curriculum_units.l1_variant)

| L1 | 조사 구간 | 어순 설명 | 발음 우선 | 한자어 |
|---|---|---|---|---|
| 일본어 | 축소 (쉬움) | 생략 | 받침 집중 | 강점 → 어휘 가속 |
| 영어 | **확대 3차시 추가** | 별도 설명 | ㅓ/ㅗ, ㅡ, 경음 | 해당 없음 |
| 중국어 | **최대 확대** | 별도 설명 | 받침, ㄹ | 부분 강점 |
| 베트남어 | 확대 | 별도 설명 | 이중모음, ㅈ/ㅊ | 부분 강점 |
| 스페인어 | 확대 | 별도 설명 | ㅡ, ㅓ, 어말자음 | 해당 없음 |

일본어권·중국어권 조사 숙달도 차이가 실증되므로 차시 배분을 다르게 한다.

## 2. 차시 자산 규격

차시 1개당 만들어야 할 것.

| 자산 | 형식 | 분량 | L1별 | 우선 |
|---|---|---|---|---|
| 강사 슬라이드 | 이미지 시퀀스(서버 렌더) | 16~20장 | ○ | P0 |
| 강사 지도안 | MD | 첫 멘트~마무리 스크립트 | ○ | P0 |
| 모델 대화 음원 | mp3 ×3 | 60~90초 (정상/70%/끊어읽기) | 공통 | **P0** |
| 롤플레이 스크립트 | MD + A/B 역할별 음원 | 1세트 | ○ | P0 |
| 시나리오 드릴 | JSON 트리 + 캐시 음원 | 2개 | ○ | P1 |
| 워크북 | PDF 2장 (QR 음원) | — | ○ | P2 |
| 발음 카드 | 이미지 | 1~2장 | L1별 | P2 |

### 슬라이드는 다운로드 불가 형식으로만 만든다

```
✕ 구글 슬라이드 복사 링크  → 학생 레코드 없이 사용 가능. 우회 경로가 됨
✕ PPTX / PDF 배포          → 첫 달에 커뮤니티에 퍼짐
○ 서버 렌더 이미지 + 워터마크 합성 + TTL 300초 서명 URL
```

**정액 구독 모델이었다면 구글 슬라이드로 충분했다. 학생 단위 과금에서는 정반대다.**

### 차시 구조 (50분 · 고정 틀)

```
0–5    지난 시간 복습 — 말로 대답. 눈으로 훑기 금지
5–12   모델 대화 듣기 → 오늘 목표 제시
12–22  핵심 표현 도입 + 패턴 드릴   ※ 설명 30초 / 반복 9분
22–35  통제된 롤플레이 (스크립트 있음)
35–45  자유 확장 — 학생이 자기 얘기로 바꿔 말하기
45–50  오류 3개만 정리 + 과제 배정

강사 설명 10분 이하 / 학생 발화 25분 이상
```

### 종료 조건은 시간이 아니라 수행

```
goal_statement 예: "카페에서 주문하고 추가 요청까지 말할 수 있다"
→ 마지막 10분 롤플레이 통과 못 하면 다음 차시로 넘어가지 않는다 (시스템이 막음)
```

### 나선형 재등장 (curriculum_units.recycle_from)

```
12차시 "-아/어 주세요"
  → 19차시 배경 대화에 등장
  → 27차시 롤플레이 필수 표현
  → 41차시 응용형 확장
```

시중 교재는 한 번 나오고 사라진다. 그래서 안 남는다.

## 3. HVPT 음원 세트 규격

**제품의 핵심 무기. 규격을 지키지 않으면 HVPT가 아니다.**

### 필수 3요건

```
① 화자 다양성      같은 소리를 화자 8명 목소리로 (5~8명이 최적)
② 음성맥락 다양성  isolated / word_initial / word_medial / sentence
③ 즉각 교정 피드백 오답 → 정답 공개 → 즉시 재생 → 재시도
```

**입모양 애니메이션은 HVPT 요건이 아니다.** 보조 자료로만 취급하고, 없어도 무방하다.

### 대립쌍 5종 (초기 제작 범위)

| id | label | tokens | 우선 L1 |
|---|---|---|---|
| g3 | ㄱ ㅋ ㄲ | 개 / 캐 / 깨 | 영어, 스페인어 |
| d3 | ㄷ ㅌ ㄸ | 달 / 탈 / 딸 | 영어, 스페인어 |
| eo | ㅓ ㅗ | 서 / 소 | 영어, 일본어 |
| eu | ㅡ ㅜ | 글 / 굴 | 영어, 일본어, 스페인어 |
| coda | 받침 ㄱ ㄴ ㅁ | 박 / 반 / 밤 | 일본어, 중국어, 베트남어 |

### 음원 개수

```
5 대립쌍 × 평균 2.6 토큰 × 화자 8 × 맥락 4 = 약 416개
전부 사전 생성 → 스토리지 캐싱 → 한계비용 0
```

TTS 생성 음원으로도 음운 인식 향상이 확인되므로 초기엔 다화자 TTS로 제작하고, 예산이 생기면 실제 화자 녹음으로 교체한다.

### 학생 화면 표기 한계 (정직성 요건)

HVPT는 **지각(듣기 구분)** 에 큰 효과가 있고, **발화 전이는 작다**(훈련 항목 10.5%, 미훈련 4.5%). 학생 대시보드 지표명은 `소리 구분 점수`로 한정하고, "발음이 좋아집니다"로 표기하지 않는다.

## 4. 시나리오 말하기 드릴

자유 대화 AI를 쓰지 않는다. **사전 제작 분기 트리 + 캐싱 음원.**

### 왜 자유 대화가 아닌가

```
비용   자유 대화: 학생당 월 $2.1 (STT+LLM+TTS) → 학생 늘수록 선형 증가
       시나리오: 학생당 월 $0.05 이하 → 사실상 0

교육   초급자는 "아무 말이나 해보세요"에서 얼어붙는다
       AI가 학생 레벨 밖 표현을 쓴다. 통제가 안 된다
       오늘 배운 문법을 안 써도 대화가 굴러간다 → 연습이 안 된다
       시나리오는 그 문형을 8번 쓰게 만든다. 안 쓰면 진행이 안 된다
```

**타협이 아니라 초급~중급에서는 더 나은 선택이다.**

### 트리 JSON 스키마

```json
{
  "unit_id": 15,
  "title": "카페에서 주문하기",
  "target_forms": ["-아/어 주세요", "-고 싶어요"],
  "nodes": [
    {
      "id": "n1",
      "speaker": "ai",
      "text": "어서 오세요. 뭐 드릴까요?",
      "audio_key": "sc/u15/n1.mp3",
      "expect": [
        { "match": ["아메리카노", "커피"], "next": "n2", "kind": "exact" },
        { "match": ["*"], "next": "n1_retry", "kind": "fallback" }
      ]
    },
    {
      "id": "n1_retry",
      "speaker": "ai",
      "text": "천천히 말해도 괜찮아요. 뭐 드릴까요?",
      "audio_key": "sc/u15/n1r.mp3",
      "hint": "아메리카노 주세요",
      "expect": [{ "match": ["*"], "next": "n2", "kind": "fallback" }]
    }
  ]
}
```

### 판정 로직 (비용 통제 핵심)

```
1차  룰 기반 문자열 매칭 (정규화: 공백·조사 변이 허용)   → 약 90% 처리, 비용 0
2차  1차 실패 시에만 LLM 판정 호출                        → 세션당 1~2회
3차  캐시: 동일 시나리오 + 동일 학생 답변 패턴 → 이전 판정 재사용

학생 음성 인식: 브라우저 Web Speech API (무료). 서버 STT 사용 금지
음성 출력:     사전 생성 캐시. 런타임 TTS 호출 금지
사용 상한:     하루 15분. 초과 시 다음 날까지 잠금 (헤비유저 적자 차단)
```

### 제작 분량

```
차시당 시나리오 2개 × AI 발화 40문장 + 분기 3~4갈래
초급 30차시 = 60개 · 개당 3시간(AI 초안 → 전문가 검수) = 180시간
→ 한국어교원 파트타임 1명 약 2개월
```

## 5. 발음 자료 (보조)

### 학습자가 반드시 막히는 6개

| # | 항목 | 왜 어려운가 | 자료 |
|---|---|---|---|
| 1 | ㅓ vs ㅗ | 영어권에 이 대립 없음 | 입술 둥글기 단면도 + 최소대립쌍 |
| 2 | ㅡ | 영어·일본어에 없는 모음 | 혀 위치 단면도 |
| 3 | ㄱ/ㅋ/ㄲ 3분 | 영어권은 유·무성 2분으로만 들음 | **종이 실험** |
| 4 | 받침 7종성 | 일본어·중국어권 최대 난관. 불파음 개념 부재 | 혀 정지 위치 |
| 5 | 연음 | 한국어[한구거]. 초급 듣기 실패의 최대 원인 | 파형 + 느린 음원 |
| 6 | 비음화·유음화 | 신라[실라] | 2급 이후 |

**3번 종이 실험은 반드시 넣는다.**
입 앞에 종이를 대고 발음 — ㅋ은 흔들리고 ㄲ은 안 흔들린다. 영어권 학습자가 평음·격음·경음을 처음으로 몸으로 구분하는 순간이고, 아무도 안 알려준다.

### 모국어별 교정 순서

```
영어권      ㅓ/ㅗ → ㅡ → 평·격·경음 → 연음
일본어권    받침 → ㅓ/ㅗ → 어두 유성음화 → 연음
중국어권    받침 → ㄹ(초성/종성 분리) → 성조 잔재 억양
베트남어권  이중모음 → ㅈ/ㅊ → (받침은 강점)
스페인어권  ㅡ → ㅓ → 어말 자음
```

**개인 강사가 절대 못 만드는 자산.** 콘텐츠 우선순위 상위에 둔다.

## 7. 4·3·2 유창성 훈련

```
같은 이야기를 4분 → 3분 → 2분으로 세 번 말한다.
내용 동일, 시간만 압축 → 자동화가 일어난다.
새 언어를 다루지 않는다. 아는 것만 쓴다.

주제 100개 (레벨별)
  1급: 주말에 뭐 했어요 / 우리 가족 / 좋아하는 음식
  2급: 한국에 온 이유 / 기억에 남는 여행
  3급: 내 나라와 한국의 다른 점

각 주제에 "쓸 표현" 4개 제시 (해당 레벨에서 이미 배운 것만)
```

강사 개입 없음. 앱에서 혼자. 한계비용 0.

## 8. 체험수업 팩 — **최우선 제작물**

양쪽 플랫폼 모두 첫 수업 실패 = 강사 수입 0이다. Preply는 체험이 무급이고, italki는 48시간 내 100% 만족보장 환불이 최대 2회 가능하다.

### 4종 (학생 목적별)

```
K-콘텐츠 / 여행 / 취업(EPS) / 유학(TOPIK)
```

### 30분 구성 (전 종 공통 틀)

```
0–3    인사 + 강사 자기소개 (한국어 100%, 느리게)
3–8    학생 목적 파악 (준비된 질문 5개, L1 병기)
8–15   한글 맛보기 — 자기 이름 쓰기      ← 성취의 순간
15–25  목적별 표현 3개 즉시 사용
       K-콘텐츠: 좋아해요 / 최고예요 / 진짜?
       여행:     주세요 / 얼마예요 / 어디예요
25–30  진도 그래프 제시 + 다음 수업 제안
```

**8–15 구간이 전환율을 결정한다.** 학생이 첫 30분에 자기 이름을 한글로 쓰고 나가면 재수강한다.

### 강사 스크립트 규격

첫 멘트부터 마무리 멘트까지 **그대로 읽으면 되는 수준**으로 작성. 강사가 판단할 여지를 남기지 않는다.

## 10. 강사 트레이닝 6모듈 (온보딩 무료 포함)

신규 강사가 무너지는 지점은 정해져 있다.

```
① 문법 설명 불가 — "왜 '저는'이고 '제가'예요?" 대부분 대답 못 함
② Teacher Talk 불가 — 학생 수준에 맞춰 속도·어휘 조절 못 함
③ 침묵을 못 견딤 — 3초 머뭇하면 자기가 답을 말함 (발화비율 70%의 원인)
```

| 모듈 | 내용 | 시간 |
|---|---|---|
| M1 | 학생 최다 질문 20개 대응 스크립트 | 2h |
| M2 | Teacher Talk + **5초 침묵 견디기 훈련** | 1h |
| M3 | 교실 영어 250문장 (앱 자율학습 2주) | 2h |
| M4 | 체험수업 30분 스크립트 숙달 | 1h |
| M5 | 모국어별 발음 교정 실습 | 1h |
| M6 | 플랫폼 운영 — 노쇼·취소·리뷰·**패키지 판매법** | 1h |

### 교실 영어 250문장 구성

```
[1] 학생이 하는 말 — 알아듣기만 (120개)
    Can you say that again? / What does ○○ mean? / How do you spell that?
    Is this formal or casual? / My internet is bad. / Slower, please.
[2] 강사가 하는 말 — 반사적으로 (100개)
    Repeat after me. / Almost! Close. / Let's practice this five times.
[3] 문법 설명 (30개)
    "은/는" is about the topic. "이/가" is about the subject.
```

**영어를 가르치지 않는다.** 250문장 암기 + 상황별 카드 + 섀도잉. 하루 20분 × 2주면 끝난다.

### 영어 사용 상한 (강사 규칙)

| 학생 레벨 | 영어 허용 | 용도 |
|---|---|---|
| 초급 1~10차시 | 최대 30% | 문법 설명 1회 + 이해 확인 |
| 초급 11차시~ | 15% | 새 문법 도입 시에만 |
| 중급 | 5% | 추상 개념만 |
| 고급 | 0% | 전면 한국어 |

**절대 규칙:** 인사·잡담·칭찬·지시는 처음부터 100% 한국어. "Good job" 대신 "잘했어요"를 첫날부터 쓴다.

## 11. 강사에게 못 박을 3가지

```
① 로마자 금지        첫 시간에 한글을 뗀다. 예외 없음
② 문법 용어 금지     "주격조사" 대신 문장 20개 반복
③ 5초 침묵 견디기    학생이 머뭇거릴 때 답을 말하지 않는다
```

추가: **말하기에서 조사 오류는 발달 단계다.** 매번 고치면 발화가 죽는다. 학생은 쓰기에서 조사를 더 정확하게 쓴다는 것이 실증되어 있다.

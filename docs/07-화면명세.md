# 07 · 화면 명세

화면 ID 규칙: `T-` 강사 · `S-` 학생 · `A-` 관리자
각 화면은 **목적 / 구성 / 상태 / 인터랙션 / 수용기준** 순으로 기술한다.

---

# T-01 · 오늘 (강사 홈)

**목적** — 강사가 앱을 열었을 때 "지금 뭘 해야 하는지"를 0.5초 안에 알게 한다.

## 구성 (위→아래)

```
① 출발 패널          (다음 수업이 15분 이내일 때만)
② 지표 3칸           이번 달 청구 / 이번 주 수업 / 평균 학생 발화
③ 학생 목록          전체, 상태 배지 포함
④ 새 학생 등록       점선 테두리, 하단 배치
```

## ① 출발 패널

| 요소 | 내용 |
|---|---|
| 맥박 점 | jade, hg-pulse 2s |
| eyebrow | `다음 수업 · Preply` |
| 학생 | 국기 + 이름(23/600) + mono `15차시 · TOPIK 1급 · 스페인어` |
| 우측 | mono 34px `14:00` + jade `8분 뒤 시작` |
| 하단 좌 | 지난 표현 태그 3개 |
| 하단 우 | 고칠 것 1줄 |
| CTA | `수업 시작 — 복습 5분부터` (흰 배경, 폭 100%) |

**표시 조건:** `GET /lessons/today` 의 `imminent === true` 인 첫 항목.
없으면 패널 자체를 렌더하지 않는다. 빈 자리를 남기지 않는다.

## ③ 학생 목록 행

```
grid: minmax(150px,1.5fr) | 1fr | 1fr | auto
  1  국기 + 이름(13.5/600) + mono 로마자명
  2  mono "14차시" · "TOPIK 1급" + 3px 진행바 (lesson/30)
  3  상태 배지 + mono 최근 활동
  4  [상세] ghost sm · [기록] primary sm
```

| 상태 | 배지 | 행 opacity | 진행바 색 |
|---|---|---|---|
| active | jade `활성` | 1 | indigo |
| dormant | chija `휴면 · 청구 없음` | .62 | chija |
| pending | honghwa `인증 대기` | .62 | chija |
| locked | honghwa `잠금` | .5 | honghwa |

목록 상단 우측 캡션: `수업 자료는 학생을 선택해야 열립니다`
— 우회 심리를 사전에 차단하는 카피. 삭제 금지.

## 수용 기준

```
□ imminent 수업이 없으면 출발 패널 미표시
□ 학생 0명일 때 목록 자리에 등록 유도 카드만 표시
□ 휴면 학생도 목록에 표시된다 (숨기지 않는다)
□ 760px 미만에서 행이 2단 카드로 재배치되고 버튼이 잘리지 않는다
□ 이번 달 청구 금액이 GET /billing/summary 와 항상 일치
```

# T-02 · 수업 진행 (4단계 플로우)

**목적** — 수업 시작 버튼 이후 강사가 아무것도 결정하지 않게 한다.

```
[획 스텝퍼] 지난 기록 — 복습 5분 — 15차시 — 기록 3분
```

## 단계 0 · 지난 기록

```
eyebrow: 강사에게만 보입니다 · 5초
· 지난 수업 새 표현 (indigo 태그)
· 고칠 것 (14px)
· 경고 박스(chija): "이번 주 복습 카드 3장 중 1장만 했습니다. 복습을 길게 잡으세요."
CTA: 복습 시작
```

경고 박스는 `prev.srs_completion < 0.5` 일 때만 표시.

## 단계 1 · 복습 5분

**직전 리포트의 expression 항목이 그대로 복습 문항이 된다.** 강사가 만들지 않는다.

```
안내: "눈으로 훑지 말고 학생이 말하게 하세요. 대답이 나와야 넘어갑니다."
행: mono 01 + 표현(17/500) + [▶ 듣기] ghost sm
CTA: 15차시 열기
```

이 구조가 리포트를 성실히 쓸 동기를 만든다. 3분 입력한 것이 다음 주에 돌아온다.

## 단계 2 · 본 차시

```
헤더  eyebrow "차시 목표" + 목표문 + [L1 판본] 태그
뷰어  16:9, 우하단 워터마크 상시
푸터  [통과 — 다음 차시 열기] jade / [재수행 — 같은 차시 반복] ghost
```

## 단계 3 · 기록 3분

→ T-03 참조.

## 수용 기준

```
□ 각 단계는 앞으로만 진행. 뒤로가기는 [나가기]뿐
□ [나가기] 시 lessons 레코드는 남고 outcome=null 로 유지
□ 뷰어에서 우클릭·Ctrl+S·Ctrl+P·드래그 전부 차단
□ 워터마크가 DOM 조작으로 제거되지 않는다 (서버 렌더 이미지에 합성)
□ 자료 URL 은 TTL 300초. 만료 시 자동 재발급
```

# T-03 · 3분 수업 리포트

**목적** — STT를 대체한다. 외부 API 호출 0건으로 학생 학습 자산을 만든다.

## 구성

```
상단   "여기 넣은 것만 학생 노트로 갑니다"  + mono 타이머 (180초 초과 시 honghwa)

카드1  오늘 나온 새 표현 · 0/5
       힌트: "전부 적지 마세요. 다음 주에 반드시 기억해야 할 것만."
       칩 목록(indigo, 클릭 시 제거) + 인풋 + [추가]

카드2  학생이 틀린 문장 · 0/3
       힌트: "말하기에서 조사 오류는 발달 단계입니다. 심한 것만."
       칩 목록(chija) + 인풋 + [추가]

CTA    [저장하고 학생에게 보내기]
       미충족 시: [새 표현을 1개 이상 입력하세요] (ghost, 비활성)
```

Enter 키로 칩 추가. 최대치 도달 시 인풋 disabled.

## 완료 화면

```
SyllableProgress(done=4) 104px
"마리아 학생에게 전달됐습니다"
"표현 3개가 학습 노트에 적립됐고, 복습 알림이 내일 · 3일 후 · 7일 후에 자동 발송됩니다.
 이 표현들이 다음 수업 복습 슬라이드가 됩니다."
jade 배지: "02:41 소요 · 음성 인식 미사용 · 추가 비용 0원"
[학생 목록으로]
```

마지막 배지는 **제품 철학의 증거**다. 삭제 금지.

## 수용 기준

```
□ expression 1개 이상 없으면 저장 불가
□ 저장 시 vocab_cards N건 생성, due_at = now+1d
□ 저장 시 notifications 5건 예약 (D+1/3/7/21/60)
□ 저장 시 외부 API 호출 0건 (테스트에서 네트워크 감시로 검증)
□ 타이머는 화면 진입 시점부터 카운트
```

# T-06 · 새 학생 등록

**목적** — 30초 안에 끝난다. 수업 직전이 아니라 예약 시점에 하도록 유도한다.

```
필드: 이름(로마자) · 한국어 이름 · 이메일 · 모국어(select) · 플랫폼(seg) · 플랫폼 URL · 목적 트랙
CTA:  [등록하고 학습 노트 보내기]
하단: "등록과 1차시는 무료입니다. 2차시부터 요금이 발생합니다."
```

완료 후:
```
✓ 학습 노트를 보냈습니다
  마리아 씨가 링크를 열면 레벨 테스트를 진행합니다.
  첫 수업 전에 끝나 있으면 50분을 온전히 수업에 쓸 수 있어요.
```

동일 이메일 존재 시(409): 새로 만들지 않고 기존 학생 상세로 이동 + 토스트
`이미 등록된 학생입니다. 이어서 진행합니다. 추가 요금은 없습니다.`

# S-02 · 소리 구분 (HVPT)

**목적** — 학습자가 못 듣던 소리를 듣게 만든다. 제품의 핵심 무기.

```
상단   [← 오늘의 학습]        mono "5/7 · 71%"
대립쌍 [ㄱ ㅋ ㄲ][ㄷ ㅌ ㄸ][ㅓ ㅗ][ㅡ ㅜ][받침 ㄱ ㄴ ㅁ]  mono 칩
       ※ 순서는 학생 L1 우선순위로 정렬

패널
  eyebrow "화자"  + 8점 인디케이터 (현재 화자만 ink)
  [▶ 다시 듣기]  ink, 폭 100%, 26px 세로 패딩
  선택지 2~3개  30px 글자, 26px 세로 패딩, grid 균등

피드백 (선택 후)
  정답: jade 박스 "맞았습니다 — 깨"
  오답: honghwa 박스 "깨 소리였습니다. 한 번 더 듣고 차이를 확인하세요."
        → 400ms 후 정답 음원 자동 재생 (즉각 교정 피드백 · HVPT 필수 요건)
  [다음 문제] indigo · 5문항 이상이면 [완료] 병기

하단 mono 캡션
  "HVPT · 화자 8 · 다중 음성환경 · 즉각 교정 피드백
   79개 연구 메타분석 g=0.92 · 음원 사전생성 캐싱 · 추가 비용 0원"
```

## 출제 규칙 (프론트·백엔드 공통)

```
· 동일 talker_idx 연속 2회 금지
· 세션당 화자 8명 전원 최소 1회 등장
· context(isolated/word_initial/word_medial/sentence) 를 섞는다
· 음원은 사전 생성 캐시만 사용. 런타임 TTS 호출 금지
· 선택 전에는 재생 버튼만 활성. 선택 후 잠금
```

## 수용 기준

```
□ 오답 시 정답 음원이 400±100ms 내 자동 재생
□ 8명 화자 인디케이터가 매 문항 갱신
□ 정답/오답이 색 + 문구 + 테두리 3중으로 구분 (색각 이상 대응)
□ 매 시도마다 student_activity(kind='hvpt') 기록
□ 음원 로드 실패 시 chija 캡션으로 안내, 앱이 멈추지 않음
```

# S-04 · 복습 카드 (SRS)

```
상단  [← 오늘의 학습]   mono "1 / 3"
카드  표현(30/600) → [뜻 보기]
      뒤집기 후: mono 영문 뜻 + surface 박스 예문(15px) + [▶ 선생님 목소리로]
등급  [어려움 1일 후] honghwa / [보통 3일 후] chija / [쉬움 7일 후] jade
```

`▶ 선생님 목소리로` — 그 표현이 나온 실제 수업 음성 클립. **일반 단어장 앱과 결정적으로 다른 지점.** 클립이 없으면 버튼 미표시(가짜 재생 금지).

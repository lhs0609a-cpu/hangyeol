# 03 · 데이터모델

PostgreSQL 15+. 모든 시각은 **UTC 저장**, 표시 시점에 타임존 변환. 예외 없음.
금액은 **정수 KRW**. 부동소수 금지.

---

## ER 개요

```
teachers ─┬─< students ─┬─< lessons ─< lesson_report_items
          │             ├─< vocab_cards
```

## 1. teachers

```sql
CREATE TABLE teachers (
  id                BIGSERIAL PRIMARY KEY,
  email             CITEXT NOT NULL UNIQUE,
  password_hash     TEXT NOT NULL,
  email_verified_at TIMESTAMPTZ,
  name              TEXT NOT NULL,
  name_en           TEXT,
  phone             TEXT,
  country_code      CHAR(2) NOT NULL DEFAULT 'KR',
  timezone          TEXT NOT NULL DEFAULT 'Asia/Seoul',
  spoken_langs      TEXT[] NOT NULL DEFAULT '{}',   -- ['en','ja']

  -- 요금 티어 산정 근거
  hourly_rate_usd   NUMERIC(6,2),
  rate_tier         CHAR(1),        -- A|B|C|D  (트리거로 자동 산정)

  italki_profile_url  TEXT,
  italki_status       TEXT DEFAULT 'none',  -- none|applied|approved|rejected
  preply_profile_url  TEXT,
  preply_status       TEXT DEFAULT 'none',

  onboarding_stage  TEXT NOT NULL DEFAULT 'signup',
      -- signup|documents|video|submitted|approved|teaching
  certified_at      TIMESTAMPTZ,

  -- 결제
  pg_customer_id    TEXT,
  card_last4        CHAR(4),
  billing_status    TEXT NOT NULL DEFAULT 'none',   -- none|ok|failed|locked
  credit_balance    INTEGER NOT NULL DEFAULT 0,     -- KRW

  created_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at        TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_teachers_billing ON teachers(billing_status);
```

### rate_tier 산정 규칙

| tier | 시급(USD) | 학생 1명 / 28일 |
|---|---|---|
| A | < 15 | 7,900원 |
| B | 15 ≤ r < 25 | 14,900원 |
| C | 25 ≤ r < 40 | 24,900원 |
| D | ≥ 40 | 39,900원 |

시급 미입력 시 기본 B. **티어 변경은 다음 주기부터 적용** (진행 중 주기는 개시 시점 요금 고정).

## 2. students

```sql
CREATE TABLE students (
  id              BIGSERIAL PRIMARY KEY,
  teacher_id      BIGINT NOT NULL REFERENCES teachers(id) ON DELETE RESTRICT,

  name            TEXT NOT NULL,          -- 표시 이름 (로마자)
  name_ko         TEXT,                   -- 한국어 이름 (강사가 부르는 이름)
  email_hash      TEXT NOT NULL,          -- sha256(lower(email) || pepper)
  email_enc       BYTEA NOT NULL,         -- AES-GCM 암호화 저장
  l1_code         CHAR(2) NOT NULL,       -- en|ja|vi|id|es|zh|de ...
  country_code    CHAR(2),

  platform        TEXT NOT NULL,          -- italki|preply|direct
  platform_url    TEXT,

  level_code      TEXT NOT NULL DEFAULT 'topik1',  -- topik1..topik6
  goal_track      TEXT,                   -- kcontent|travel|business|topik|eps

  status          TEXT NOT NULL DEFAULT 'pending',
      -- pending|active|dormant|locked|completed
  verified_at     TIMESTAMPTZ,            -- 학생 이메일 인증 시각

  current_lesson_no  INTEGER NOT NULL DEFAULT 0,
  first_lesson_at    TIMESTAMPTZ,
  last_lesson_at     TIMESTAMPTZ,

  created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT now(),

  CONSTRAINT uq_student_email UNIQUE (teacher_id, email_hash)
);

CREATE INDEX idx_students_teacher_status ON students(teacher_id, status);
CREATE INDEX idx_students_last_lesson ON students(last_lesson_at);
```

### status 상태 정의

| status | 의미 | 자료 열람 | 과금 |
|---|---|---|---|
| pending | 등록됨, 이메일 미인증 | **3차시까지만** 가능 | 2차시부터 발생 |
| active | 정상 진행 | 가능 | 발생 |
| dormant | 28일간 수업 0회 | 읽기전용 | **없음** |
| locked | 강사 결제 실패 | 강사 차단 / 학생은 읽기전용 | 미납 |
| completed | 과정 종료 | 읽기전용 아카이브 | 없음 |

## 3. lessons

```sql
CREATE TABLE lessons (
  id            BIGSERIAL PRIMARY KEY,
  student_id    BIGINT NOT NULL REFERENCES students(id) ON DELETE CASCADE,
  teacher_id    BIGINT NOT NULL REFERENCES teachers(id),
  lesson_no     INTEGER NOT NULL,
  unit_id       BIGINT REFERENCES curriculum_units(id),

  started_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  ended_at      TIMESTAMPTZ,

  outcome       TEXT,          -- pass|repeat
  speak_ratio   SMALLINT,      -- 0~100, 학생 발화 비율 (볼륨 기반)

  report_submitted_at TIMESTAMPTZ,
  billing_cycle_id    BIGINT REFERENCES billing_cycles(id),

  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),

  CONSTRAINT uq_lesson_no UNIQUE (student_id, lesson_no, started_at)
);

CREATE INDEX idx_lessons_student ON lessons(student_id, started_at DESC);
CREATE INDEX idx_lessons_cycle ON lessons(billing_cycle_id);
```

## 4. lesson_report_items

```sql
CREATE TABLE lesson_report_items (
  id         BIGSERIAL PRIMARY KEY,
  lesson_id  BIGINT NOT NULL REFERENCES lessons(id) ON DELETE CASCADE,
  kind       TEXT NOT NULL,     -- expression|error
  body       TEXT NOT NULL,

CREATE INDEX idx_report_lesson ON lesson_report_items(lesson_id, kind);
```

제약: `kind='expression'` 최대 5개, `kind='error'` 최대 3개. 애플리케이션 레이어에서 강제.

## 5. vocab_cards (SRS)

```sql
CREATE TABLE vocab_cards (
  id              BIGSERIAL PRIMARY KEY,
  student_id      BIGINT NOT NULL REFERENCES students(id) ON DELETE CASCADE,
  source_lesson_id BIGINT REFERENCES lessons(id),

  term            TEXT NOT NULL,
  gloss_l1        TEXT,
  example         TEXT,
  audio_key       TEXT,          -- 그 표현이 나온 수업의 음성 클립 (선택)

  -- SM-2 계열
  ease            NUMERIC(4,2) NOT NULL DEFAULT 2.50,
  interval_days   INTEGER NOT NULL DEFAULT 1,
  reps            INTEGER NOT NULL DEFAULT 0,
  lapses          INTEGER NOT NULL DEFAULT 0,
  due_at          TIMESTAMPTZ NOT NULL,
  state           TEXT NOT NULL DEFAULT 'learning', -- learning|review|graduated

  created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_vocab_due ON vocab_cards(student_id, due_at) WHERE state <> 'graduated';
```

### SRS 스케줄 규칙

```
등급        ease 변화     다음 간격
어려움      -0.20        1일          (lapses += 1, state=learning)
보통        -0.02        interval × 1.6
쉬움        +0.10        interval × ease

최소 ease 1.30. 3회 연속 '쉬움' → state='graduated'
고정 체크포인트: D+1, D+3, D+7, D+21, D+60 (알림 발송 기준)
```

## 7. HVPT

```sql
CREATE TABLE hvpt_contrasts (
  id        TEXT PRIMARY KEY,        -- 'g3','d3','eo','eu','coda'
  label     TEXT NOT NULL,           -- 'ㄱ ㅋ ㄲ'
  note      TEXT,                    -- '평음 · 격음 · 경음'
  tokens    TEXT[] NOT NULL,         -- ['개','캐','깨']
  l1_priority JSONB                  -- {"en":1,"ja":3,"vi":2}
);

CREATE TABLE hvpt_tokens (
  id           BIGSERIAL PRIMARY KEY,
  contrast_id  TEXT NOT NULL REFERENCES hvpt_contrasts(id),
  token        TEXT NOT NULL,
  talker_idx   SMALLINT NOT NULL,    -- 0..7  (화자 8명)
  context      TEXT NOT NULL,        -- 'isolated'|'word_initial'|'word_medial'|'sentence'
  audio_key    TEXT NOT NULL,        -- 사전 생성된 음원 (런타임 TTS 금지)
  CONSTRAINT uq_hvpt_token UNIQUE (contrast_id, token, talker_idx, context)
);

CREATE TABLE hvpt_sessions (
  id          BIGSERIAL PRIMARY KEY,
  student_id  BIGINT NOT NULL REFERENCES students(id) ON DELETE CASCADE,
  contrast_id TEXT NOT NULL REFERENCES hvpt_contrasts(id),
  attempts    SMALLINT NOT NULL DEFAULT 0,
  correct     SMALLINT NOT NULL DEFAULT 0,
  started_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
  ended_at    TIMESTAMPTZ
);

CREATE TABLE hvpt_attempts (
  id           BIGSERIAL PRIMARY KEY,
  session_id   BIGINT NOT NULL REFERENCES hvpt_sessions(id) ON DELETE CASCADE,
  token_id     BIGINT NOT NULL REFERENCES hvpt_tokens(id),
  chosen       TEXT NOT NULL,
  is_correct   BOOLEAN NOT NULL,
  response_ms  INTEGER,
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

**화자 다양성 요건:** 한 세션에서 동일 talker_idx가 연속 2회를 넘지 않도록 출제기가 보장한다. 화자 8명 전원이 세션당 최소 1회 등장.

## 8. 4·3·2 · 다청 · Four Strands

```sql
CREATE TABLE fluency_sessions (
  id           BIGSERIAL PRIMARY KEY,
  student_id   BIGINT NOT NULL REFERENCES students(id) ON DELETE CASCADE,
  topic_id     BIGINT,
  r1_done_at   TIMESTAMPTZ,
  r2_done_at   TIMESTAMPTZ,
  r3_done_at   TIMESTAMPTZ,
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE listening_logs (
  id           BIGSERIAL PRIMARY KEY,
  student_id   BIGINT NOT NULL REFERENCES students(id) ON DELETE CASCADE,
  audio_id     BIGINT NOT NULL,
  played_sec   INTEGER NOT NULL DEFAULT 0,
  completed_at TIMESTAMPTZ,
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE strand_weekly (
  student_id   BIGINT NOT NULL REFERENCES students(id) ON DELETE CASCADE,
  week_start   DATE NOT NULL,          -- 월요일 (UTC 기준 계산 후 학생 TZ 보정)
  input_min    INTEGER NOT NULL DEFAULT 0,
  output_min   INTEGER NOT NULL DEFAULT 0,
  form_min     INTEGER NOT NULL DEFAULT 0,
  fluency_min  INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY (student_id, week_start)
);
```

### Four Strands 집계 매핑

| 활동 | 스트랜드 | 분 계산 |
|---|---|---|
| 다청 (listening_logs) | input | played_sec / 60 |
| 수업 중 학생 발화 | output | lesson 길이 × speak_ratio |
| 시나리오 말하기 드릴 | output | 실제 소요 |
| SRS · HVPT · 워크북 | form | 실제 소요 |
| 4·3·2 | fluency | 9분 고정 |
| 수업 중 강사 발화 | input | lesson 길이 × (100−speak_ratio) |

경고 기준: `form > 25%` 또는 `fluency < 25%` 또는 `|input−25| > 8%`

## 9. 커리큘럼

```sql
CREATE TABLE curriculum_units (
  id             BIGSERIAL PRIMARY KEY,
  level_code     TEXT NOT NULL,            -- topik1..topik6
  unit_no        INTEGER NOT NULL,         -- 전역 차시 번호 1..250
  title          TEXT NOT NULL,
  goal_statement TEXT NOT NULL,            -- "카페에서 주문하고 추가 요청까지 말할 수 있다"
  target_forms   JSONB NOT NULL,           -- ["-아/어 주세요","-고 싶어요"]
  target_vocab   JSONB NOT NULL,
  recycle_from   INTEGER[],                -- 나선형 재등장: 어느 차시 표현을 다시 쓰는가
  CONSTRAINT uq_unit_no UNIQUE (unit_no)
);

CREATE TABLE curriculum_assets (
  id          BIGSERIAL PRIMARY KEY,
  unit_id     BIGINT NOT NULL REFERENCES curriculum_units(id) ON DELETE CASCADE,
  l1_code     CHAR(2) NOT NULL,     -- 'xx' = 공통
  kind        TEXT NOT NULL,
     -- slide | audio_model | audio_slow | audio_chunk
     -- | worksheet_pdf | roleplay_script | pron_sheet
  storage_key TEXT NOT NULL,
  page_count  SMALLINT,
  duration_sec INTEGER,
  CONSTRAINT uq_asset UNIQUE (unit_id, l1_code, kind)
);

CREATE TABLE scenarios (
  id            BIGSERIAL PRIMARY KEY,
  unit_id       BIGINT NOT NULL REFERENCES curriculum_units(id) ON DELETE CASCADE,
  title         TEXT NOT NULL,
  tree          JSONB NOT NULL,     -- 분기 트리 (08번 문서 스키마)
  tts_generated_at TIMESTAMPTZ
);
```

## 10. 과금

```sql
CREATE TABLE billing_cycles (
  id            BIGSERIAL PRIMARY KEY,
  student_id    BIGINT NOT NULL REFERENCES students(id) ON DELETE CASCADE,
  teacher_id    BIGINT NOT NULL REFERENCES teachers(id),
  cycle_no      INTEGER NOT NULL,

  period_start  TIMESTAMPTZ NOT NULL,
  period_end    TIMESTAMPTZ NOT NULL,       -- period_start + 28d

  tier          CHAR(1) NOT NULL,           -- 개시 시점 고정
  base_amount   INTEGER NOT NULL,
  discount_pct  SMALLINT NOT NULL DEFAULT 0,
  amount        INTEGER NOT NULL,           -- 실제 청구액

  lesson_count      SMALLINT NOT NULL DEFAULT 0,
  activity_count    SMALLINT NOT NULL DEFAULT 0,

  status        TEXT NOT NULL DEFAULT 'open',
     -- open | billable | waived_dormant | invoiced | paid | failed
  closed_at     TIMESTAMPTZ,

  CONSTRAINT uq_cycle UNIQUE (student_id, cycle_no)
);

CREATE INDEX idx_cycle_close ON billing_cycles(status, period_end);
CREATE INDEX idx_cycle_teacher ON billing_cycles(teacher_id, status);

CREATE TABLE invoices (
  id             BIGSERIAL PRIMARY KEY,
  teacher_id     BIGINT NOT NULL REFERENCES teachers(id),
  billing_month  DATE NOT NULL,            -- 2026-09-01
  total_amount   INTEGER NOT NULL,
  credit_applied INTEGER NOT NULL DEFAULT 0,
  charge_amount  INTEGER NOT NULL,         -- total - credit_applied
  status         TEXT NOT NULL DEFAULT 'pending',
     -- pending | paid | failed | grace | locked | void
  pg_tid         TEXT,
  paid_at        TIMESTAMPTZ,
  failed_at      TIMESTAMPTZ,
  retry_count    SMALLINT NOT NULL DEFAULT 0,
  grace_until    TIMESTAMPTZ,
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
  CONSTRAINT uq_invoice UNIQUE (teacher_id, billing_month)
);

CREATE TABLE invoice_lines (
  id               BIGSERIAL PRIMARY KEY,
  invoice_id       BIGINT NOT NULL REFERENCES invoices(id) ON DELETE CASCADE,
  billing_cycle_id BIGINT NOT NULL REFERENCES billing_cycles(id),
  student_id       BIGINT NOT NULL REFERENCES students(id),
  amount           INTEGER NOT NULL
);

CREATE TABLE credit_topups (
  id          BIGSERIAL PRIMARY KEY,
  teacher_id  BIGINT NOT NULL REFERENCES teachers(id),
  paid_amount    INTEGER NOT NULL,
  granted_amount INTEGER NOT NULL,
  bonus_pct   SMALLINT NOT NULL,
  pg_tid      TEXT,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

## 11. asset_views — 열람 로그 · 우회 감지

```sql
CREATE TABLE asset_views (
  id          BIGSERIAL PRIMARY KEY,
  teacher_id  BIGINT NOT NULL REFERENCES teachers(id),
  student_id  BIGINT NOT NULL REFERENCES students(id),
  unit_id     BIGINT NOT NULL REFERENCES curriculum_units(id),
  asset_id    BIGINT REFERENCES curriculum_assets(id),
  opened_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
  ip_hash     TEXT,
  ua_hash     TEXT

CREATE INDEX idx_views_student_time ON asset_views(student_id, opened_at DESC);
```

**student_id 는 NOT NULL.** 학생 없이 자료를 여는 경로는 존재하지 않는다.

## 12. 보조 테이블

```sql
CREATE TABLE notifications (
  id          BIGSERIAL PRIMARY KEY,
  target_type TEXT NOT NULL,      -- teacher|student
  target_id   BIGINT NOT NULL,
  kind        TEXT NOT NULL,      -- srs_due|cycle_billed|payment_failed|langgate_open|package_hint

CREATE INDEX idx_notif_due ON notifications(scheduled_at) WHERE sent_at IS NULL;

CREATE TABLE lang_gate_snapshots (
  id          BIGSERIAL PRIMARY KEY,

  lang_code   CHAR(2) NOT NULL DEFAULT 'ko',
  is_open     BOOLEAN NOT NULL,

CREATE TABLE audit_log (
  id          BIGSERIAL PRIMARY KEY,
  actor_type  TEXT NOT NULL,
  actor_id    BIGINT,
  action      TEXT NOT NULL,
  entity      TEXT,
  entity_id   BIGINT,
  meta        JSONB,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
```

## 13. 저장 금지 항목

```
✕ 학생 이메일 평문 (email_enc 암호화 + email_hash 만)
✕ 수업 음성 원본 파일 (STT 미사용, 저장하지 않음)
✕ 강사 플랫폼 로그인 자격증명 (절대 수집 금지)
✕ 학생 결제 정보 (우리는 학생에게 과금하지 않는다)
✕ 카드번호 (PG 빌링키만 보관)
```

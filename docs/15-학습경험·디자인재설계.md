# 학습 경험과 디자인 재설계 — 2026-09-08

사용자 요청에 따라 홈페이지부터 교재까지 학습자 중심으로 다시 설계했다. 이 문서는 06번의 폰트·크기·팔레트와 13번의 랜딩 순서에 관한 이전 결정을 대체한다. 인증, 강사 승인, 수업 과금, 개인 학생 노트의 접근 제어는 기존 구조를 사용한다.

## 이용 흐름

- 공개 홈페이지: 영어 기본, 한국어 전환. 실제 사용 상황 → 교재 체험 → 학습 순서 → 강사 안내 → FAQ → 학습 시작.
- `/learn`: 계정 없이 사용할 수 있는 독립적인 14미션 입문 교재. 목적(한글/여행/대화)과 하루 권장 연습 목표 선택. 모든 미션 직접 접근 가능.
- 연습: 장면 → 단어 → 핵심 표현과 문형 → 대화 → 이해 확인 → 말하기 자기 점검 → 이전 표현 재등장.
- 완료: 이해 확인 문항을 모두 맞히고 소리 내어 연습했다고 스스로 확인해야 완료 기록. 말하기 능력의 자동 평가나 공인 숙련도 인증이 아니다.
- 저장: 버전과 유효한 미션 ID를 검사한 브라우저 로컬 저장. 진도, 학습 목표, 안내 언어, 미션별 메모. 계정 동기화나 강사 공유는 없음. 저장 실패를 화면에 표시.
- `/learn/print`: 14미션 전부와 별도 정답·말하기 예시, 필기 영역을 포함한 인쇄/PDF 저장 화면.
- 학생 개인 노트: 선생님이 발급한 링크로 접근. 공개 교재를 강사 회원 신청으로 잘못 안내하지 않는다.
- `/signup`: 강사 신청임을 명확히 표시. 실제 신청 API와 승인 흐름을 유지하며, 외국인 학습자에게는 공개 교재를 안내.

## 폰트와 화면 원칙

DM Sans는 영문 안내·탐색·본문, Noto Sans KR은 한국어 본문·교재 문장에 사용한다. 영문 마케팅 강조에만 시스템 Georgia 이탤릭을 사용한다. 한글에는 이탤릭을 적용하지 않는다. 숫자는 시스템 고정폭 글꼴 또는 tabular-nums를 사용한다. 공식 Google Fonts 저장소에서 폰트와 OFL 라이선스를 받아 `packages/ui/fonts`에 보관하고, 400–600 굵기 범위의 WOFF2를 `next/font/local`로 제공한다. 모든 글리프는 유지한다. 빌드 시 외부 폰트 요청이 없으며 display: swap과 시스템 대체 글꼴을 둔다.

| 역할 | 운영 화면 | 학생 노트 | 공개 홈페이지·교재 |
|---|---|---|---|
| 본문 | 15px | 16px | 16px |
| 보조 본문 | 14px | 14px | 14px |
| 설명 | 12.5px | 13px | 13px |
| 한국어 핵심 표현 | 역할 토큰 | 역할 토큰 | 24–36px |
| 큰 제목 | 28px | 26px | 반응형 32–64px |

배경은 따뜻한 종이색, 주요 행동은 짙은 청록색, 문형 설명과 완료는 연녹색, 장면의 따뜻한 강조는 살구색. 색 외에 라벨·번호·체크 표시로 상태를 구분한다. 입력·링크·버튼은 주요 동작에서 최소 44px 높이. 키보드 포커스 유지, 모바일 한 열 배치, 이미지의 한국어와 대체 텍스트 제공, 움직임 줄이기 설정 존중.

## 콘텐츠 범위와 정직한 안내

14미션은 한글 입문 두 장, 인사, 카페, 식당, 쇼핑, 방향, 이동, 일상, 취향, 과거, 계획, 대화 복구, 종합 미션으로 구성한다. 장면마다 영한 목표·단어·표현·대화·문형·문화 설명·객관식 두 문항과 해설·자기 표현 과제·예시를 제공한다. 10–15분은 권장 연습량이며 최단 학습 기간 또는 유창성 보장이 아니다.

기존 70차시의 강사 지도안을 대체하거나 완료했다고 표시하지 않는다. 공개 입문 미션은 관련 강사 차시를 연결하는 메타데이터를 갖는다. 기존 슬라이드는 공통 글꼴과 읽기 쉬운 레이아웃을 사용하고, 장면에 맞는 공용 일러스트를 표지·대화·역할극에 사용한다. 어휘마다 정확한 사물 사진이 있는 것처럼 표현하지 않는다.

음원·발음 자동 채점은 제공하지 않는다. 로마자는 선택 가능한 대략적 읽기 도움말이고 발음은 한국어 화자/강사와 연습한다. 교재의 가격과 버스 대화는 가상의 예시다. 교수자 최종 언어 검수는 별도 검토 항목으로 남는다.

## 이미지 자산

내장 image_gen으로 독립 생성한 6장: 서울 골목, 카페, 식당, 교통, 가게, 친구·선생님 대화. 실제 수강생 사진이나 고객 후기가 아닌 교재용 일러스트다. 한국어 문장과 정답은 이미지에 생성하지 않고 HTML 텍스트로 조판한다. 원본 PNG와 최적화 WebP를 프로젝트에 보관한다. 프롬프트 전문은 `docs/learning-image-prompts.json` 참조.

공개 이미지 경로: `apps/teacher/public/photos/learning/`. `/photos/`는 기존 공개 자산 경로다. 인증이 필요한 교재나 학생 자료를 공개 디렉터리로 옮기지 않는다.

## 검증

내용 참조·복습 순서·정답 범위·저장 데이터 오염 방어 테스트, 기존 전체 테스트, 두 앱 타입 검사, 디자인·화이트라벨·라이선스 검사, 운영 빌드와 모바일·데스크톱 브라우저 검증을 수행하고 결과를 작업 보고에 기록한다.

## 로컬 확인과 결과물

공개 교재는 14미션, 어휘 항목 56개(복습 재등장 포함), 핵심 표현 43개, 이해 확인 28문항으로 구성한다. 기존 강사 70차시의 표지·대화·역할극에도 공용 장면을 연결했다.

이미 포함된 WOFF2와 WebP를 사용하므로 일반 빌드에 폰트 다운로드나 이미지 생성 도구가 필요하지 않다.

```powershell
npm.cmd run build --workspace @hangyeol/teacher
node node_modules/next/dist/bin/next start apps/teacher -H 127.0.0.1 -p 3217
```

`http://127.0.0.1:3217/`에서 홈페이지, `/learn`에서 교재, `/learn/print`에서 전체 인쇄본을 확인한다. 학생 앱은 `@hangyeol/note`를 빌드하고 같은 실행 명령의 앱 경로와 포트를 `apps/note`, `3218`로 바꾼다.

브라우저 검증은 선택적으로 설치한 Playwright와 로컬 Edge를 사용하는 `tools/check-learning-browser.mjs`, `tools/check-note-browser.mjs`로 재현한다. 교재 데이터 검증은 `npm.cmd test`. 스크린샷·브라우저 검사 기록·인쇄 PDF는 `output/design-review/`에 생성한다. 이 폴더는 재생성 가능한 로컬 결과물이어서 Git에서 제외한다.

`tools/compact-learning-pdf.py`는 생성된 PDF에 페이지 번호를 추가하고 그림을 배포용으로 압축한다. 원문 텍스트가 모두 유지되는지 재검증한 별도 `samat-first-steps-workbook-compact.pdf`를 만든다. 교재 원본은 `/learn/print`의 구조화된 텍스트와 원본 이미지다.

실계정 데이터 변경·외부 배포 없이 검증한다. 신청과 학생 복습 API는 브라우저 검사에서 테스트 응답으로 대체한다. 교사 홈 레이아웃 검사는 유효하지 않은 로컬 검사 쿠키로 인증되지 않은 예시 화면만 사용한다.

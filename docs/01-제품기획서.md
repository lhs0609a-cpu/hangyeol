# 01 · 제품기획서

## 1. 배경

온라인 언어학습 시장은 2026년 244억 달러 규모이며 2031년 508억 달러로 성장 전망(연 15.83%). 다만 영어가 온라인 학습의 91%를 차지하므로 **한국어는 규모가 작은 버티컬**이다. 규모를 과대평가하지 않는다.

한국어 강사는 italki와 Preply에 집중되어 있다.

| | italki | Preply |
|---|---|---|
| 설립 | 2007, 홍콩 | 2012, 미국(우크라이나 창업) |
| 학습자 | 1,000만+ | 미공개 |
| 강사 | 3만+ | 10만+ |
| 최근 조달 | 2016년 300만 달러가 마지막 | 2026.1 시리즈D 1.5억 달러, 밸류 12억 달러 |
| 한국어 강사(참고) | 약 230명 | 585명 |
| 강사 수수료 | 단일수업 약 21% (15%에서 인상) | 33% → 누적시간 따라 18%까지 |
| 체험수업 | 유료, 강사가 받음 | **강사 몫 0원** |
| 학생 결제 | 크레딧 선충전, 건별 소진 | 28일 구독 자동결제 |
| 교재 제공 | **없음 (강사가 직접 제작)** | 있음 |
| 지원 절차 | 복잡 (ID·셀피·영상·자격증빙), 최대 10영업일 | 간소, 1~7일 |
| 언어 오픈 게이트 | **있음** (매주 월 갱신, 언제든 닫힘) | 없음 |

> 수수료율은 수시로 변경된다. 개발 착수 시 강사 계정으로 실제 화면을 캡처해 확정할 것.

## 2. 문제 정의

### 강사 측

| 문제 | 실태 |
|---|---|
| 진입 장벽 | italki 지원 평균 34일, 절반이 소개영상 단계에서 포기 |
| 언어 오픈 게이트 | 한국어 창구가 닫혀 있으면 신청 자체 불가. 대부분 모르고 포기 |
| 영어 부담 | "영어 못해서 못 한다"가 가장 큰 진입 차단 요인 |
| 수업 준비 | italki는 교재 미제공. 차시당 1~2시간 준비 |
| 체험수업 실패 | Preply 체험은 무급. 전환 실패 = 공짜 노동 |
| 자기 습관 무지 | 발화 비율 70%를 본인이 모름 |

### 학생 측 — 실력이 안 느는 3대 병목

```
병목 1 · 출력 부재
   수업 50분 중 학생 발화 15분. 나머지 6일은 한 마디도 안 함.
   → "이해는 되는데 말이 안 나온다"의 실체

병목 2 · 망각이 학습보다 빠름
   50분에 새 표현 12개 → 1주 뒤 기억 3개 → 밑빠진 독

병목 3 · 발음 미교정
   특히 평음/격음/경음과 ㅓ/ㅗ를 '못 듣는' 것이 좌절의 최대 원인
```

## 3. 해결 방식과 근거

| 병목 | 해결 장치 | 근거 |
|---|---|---|
| 출력 부재 | 시나리오 말하기 드릴 · 4·3·2 유창성 훈련 | Nation Four Strands — 유창성 개발에 수업시간 25% 이상 배정 필요 |
| 망각 | SRS 간격 반복 (수업 표현 자동 적립) | 간격 반복 표준 |
| 발음 | HVPT 지각훈련 | 79개 연구 메타분석 g=0.92(사전사후), g=0.67(대조군). 장기 유지 확인 |
| 균형 붕괴 | Four Strands 시간 배분 자동 추적 | 언어중심 학습 25% 이하, 유창성 25% 이상 |

### HVPT를 핵심 무기로 삼는 이유

- 효과가 메타분석으로 입증됨
- **교사 대부분이 모른다.** 연구가 기술 저널에 실려 교사 접근이 어렵기 때문
- 실험실보다 **집에서 훈련할 때 향상이 더 큼** → 앱 구조에 최적
- TTS 생성 음원으로도 효과 확인 → 사전 생성·캐싱으로 한계비용 0

**한계도 명시한다.** HVPT는 지각(듣기 구분)에 큰 효과, 발화 전이는 작다(훈련 항목 10.5%, 미훈련 4.5%). 발화 장기 유지·일반화의 강한 근거는 없다. 마케팅은 "듣기 구분 능력"으로 한정한다.

### 근거가 약해 마케팅 금지 항목

| 문구 | 상태 |
|---|---|
| "학생 발화 50% 이상" | 방향은 맞으나 수치 근거 없음. 내부 목표치로만 사용 |
| "로마자 절대 금지" | 널리 권장되나 비교 실험 근거 미확인 |
| "상위 500단어가 대화의 70%" | 한국어 실측치 미확인 |
| "발음은 3개월에 고착" | 과장. 임계기 가설은 논쟁 중 |

검증된 것은 **HVPT와 Four Strands 둘뿐**이다. 이 둘로만 마케팅한다.

## 4. 타깃

### 1차 타깃 강사

```
· 한국어교원 자격 2·3급 보유자 및 양성과정 수료생
· 한국어교육 전공 대학원생
· 경력단절 후 재취업 희망자
· 해외 거주 교포
공통점: 한국어를 가르칠 수 있으나 진입 방법을 모르고, 영어에 부담을 느낀다
```

### 강사 모집 경로 (우선순위)

| 순위 | 경로 | CAC |
|---|---|---|
| 1 | **한국어교원 양성과정 운영기관 제휴** — 수료생 진출 패키지를 기관에 붙임 | 거의 0 |
| 2 | italki 한국어 창구 오픈 알림 무료 구독 (리드 자석) | 낮음 |
| 3 | 네이버카페 한국어교원 커뮤니티 | 낮음 |
| 4 | 유튜브 "집에서 한국어 가르쳐서 월 100만원" | 중 |

### 학생

강사가 데려온다. 우리가 직접 모집하지 않는다(Phase 3 제외).
모국어 지원 우선순위: 영어 · 일본어 · 베트남어 · 인도네시아어 · 스페인어.

## 5. 사업 모델

### 두 개의 상품을 분리 인식한다

```
[상품 A] 강사 진입 지원   — 온보딩·소개영상·교실영어·창구알림
         학습 효과 0. 무료. 강사 모집용 미끼.

[상품 B] 학습 엔진        — HVPT·드릴·SRS·다청·커리큘럼·수업도구
         과금 대상. 실력을 만드는 물건.
```

이 경계를 흐리면 요금 논쟁에서 밀린다.

### 과금

| 항목 | 값 |
|---|---|
| 단위 | 활성 학생 1명 / 28일 |
| 등록 | 0원 |
| 1차시 | 0원 |
| 2차시 진입 | 첫 과금 발생, 28일 주기 개시 |
| 요금 | 시급 $15↓ 7,900 / $15–25 14,900 / $25–40 24,900 / $40↑ 39,900 |
| 볼륨 할인 | 활성 11명↑ 20% |
| 휴면 | 28일간 수업 0회 → 청구 없음, 주기 정지 |
| 청구 | 학생별 계산, 카드는 월 1회 합산 |
| 선충전 | 50만원 충전 시 60만원 사용 (20% 보너스) |

### 왜 30% 성과 수수료가 아닌가

```
· 우리는 결제 흐름 밖에 있어 강사 수입을 검증할 수 없다
· 카드 정기결제 해지는 클릭 한 번. 회수율 추정 20~35%
· 수입 연동 금전 수취는 직업안정법상 유료직업소개사업 해석 위험
· italki 21% + 우리 30% = 51%. 강사가 계산기를 두드리면 떠난다
```

정액 학생 단위 과금은 회수율 95%+, 법적으로 SaaS 이용료로 명확하다.

## 6. 경쟁·해자

| 자산 | 개인 강사 복제 가능? | 경쟁사 복제 가능? |
|---|---|---|
| HVPT 지각훈련 엔진 | 불가능 | 가능하나 아무도 안 함 |
| 모국어별 5개 판본 커리큘럼 | 불가능 | 고비용 |
| Four Strands 자동 추적 | 불가능 | 데이터 필요 |
| 학생 학습 이력·단어장 | 불가능 | 불가능 (우리 DB) |
| 250차시 콘텐츠 | 불가능 | 6~12개월 |

**진짜 해자는 콘텐츠가 아니라 학생 데이터다.** 콘텐츠는 6개월이면 강사가 다 소진하지만, 학생은 매번 새로 온다.

## 7. 리스크

| 리스크 | 심각도 | 대응 |
|---|---|---|
| **플랫폼 정책 변경** | 치명 | Phase 3 자체 전환을 12~18개월 내 실행 항목으로 고정 |
| italki 한국어 창구 폐쇄 | 높음 | Preply 우선 등록으로 우회 |
| 강사가 등록 없이 자료만 사용 | 높음 | 자료 다운로드 전면 차단, 학생 레코드 없으면 열람 불가 |
| 학생이 튜터 갈아탐 (Preply) | 중 | 학습 이력 락인 + 강사 유지 트레이닝 |
| 콘텐츠 무단 공유 | 중 | 학생명 워터마크 + 열람 로그 + 이상패턴 플래그 |
| 강사 계정 정지 | 치명 | 09번 문서 레드라인 절대 준수 |
| 종량과금 폭증 | 중 | STT·LLM·TTS 전면 제거 또는 캐싱 (10번 문서) |

## 8. 로드맵

```
Phase 0  (0~8주)   코드 0줄. 강사 20명 무료 온보딩, 학생 20명 A/B 12주 파일럿
                   목표 지표: TOPIK 모의 향상, 12주 잔존율, italki 승인 소요일
Phase 1  (2~4개월) P0 3종 + 결제 + 체험팩 + 초급 30차시
Phase 2  (5~8개월) HVPT·SRS·4·3·2 · 발음 시트 5종 · 온보딩 스튜디오
Phase 3  (12~18개월) 자체 채널 학생 확보 → 자체 플랫폼 전환
```

**Phase 0의 목적은 숫자 하나를 만드는 것이다.**
"우리 도구를 쓴 학생은 12주 후 TOPIK 점수 1.8배, 잔존율 82% vs 45%"
이 숫자가 없으면 이 문서 전체가 주장에 불과하다.

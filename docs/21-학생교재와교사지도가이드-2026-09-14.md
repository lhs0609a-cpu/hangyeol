# 학생 교재와 교사 지도 가이드

정규 250차시에 학생용 4단계 교재(그림 관찰, 대화와 표현, 지원을 받는 연습, 독립 수행)와 교사용 가이드를 연결했다. 교수 플랜과 실제 수업 화면에서 같은 교재를 보며 지도한다. 교사용 창에서 연 학생 제시용 창은 학생 자료만 서버에서 받는다. 같은 브라우저의 BroadcastChannel로 페이지와 대화 가리기를 연동한다. 서로 다른 기기의 실시간 동기화 기능은 아니다.

교사 가이드는 읽기·어휘·듣기·문장 구성·독립 말하기·상호작용의 6영역에 확인 질문, 기대 반응, 어려움의 신호, 원인 구별 방법, 보강 순서, 재확인 과제를 제공한다. 단원 어휘·문형·예문과 1~6급별 지원 방식을 반영한다. 기존 상세 대본과 지도안도 유지한다.

관찰하지 않은 영역은 미확인으로 남긴다. 어려움이나 독립 수행을 기록하려면 실제 관찰 근거가 필요하고, 보강 후 재확인에는 별도 근거를 요구한다. 학생 답안과 도움 요청, 최근 수업의 오류·표현, 다른 단원의 보강 필요 기록도 교사 화면에서 확인한다. 과거 기록은 현재 상태와 구분해 날짜·차시를 표시한다. 자동 음성 평가나 지식 상태 확정 진단은 하지 않는다.

관찰 기록은 `student_activity.kind = teaching_observation`으로 저장하고 과금용 활동 집계, 학습 활동·연속 학습일 집계에서 제외한다. 교사와 학생 소유권·잠금 상태를 확인하고, 학생별 잠금과 단원별 revision으로 오래된 저장을 거부한다. 관찰 저장 자체는 수업 통과나 진도를 변경하지 않는다. 학생 도움 요청은 답안 없이 저장할 수 있고, 기존 답안·완료 기록을 덮어쓰지 않는다.

## 이미지

내장 image_gen으로 교실·직장·병원·주거·문화·자료 분석·환경의 새 삽화 7종을 제작했다. PNG 원본과 WebP 배포본은 `apps/teacher/public/photos/learning/`, 학생 배포본은 `apps/note/public/photos/learning/`에 저장했다. 최종 프롬프트는 `docs/coursebook-image-prompts-2026-09-13.json`에 기록했다. 기존 8종을 포함해 총 15종이며, 단원별 장면·질문·확장 활동에 재사용한다. 단원마다 별개의 고유 삽화 250종을 제작한 것은 아니다.

## 검증

- 전체 331개 테스트 실행에서 발견한 2개 실패를 수정하고 해당 파일들을 재실행해 통과했다.
- 공용 패키지와 두 앱 타입 검사 통과.
- 교사용·학생용 Next 배포 빌드 모두 통과.
- `tools/check-classroom-browser.mjs`: 실제 빌드의 화면을 UI fixture로 검증했다. 교사 기록 분리, 창 간 연동, 대화 가리기, 저장 후 복원, 답안 없는 도움 요청, 390/768/1440px 가로 넘침 없음 및 런타임 오류 없음 확인.
- 브라우저 결과와 스크린샷: `output/design-review/classroom-*`. API 권한과 학생 응답 분리는 별도 테스트에서 검증했다.

실제 운영 DB 저장·동시성 부하, 한국어교원 검수, 실제 학습자 수업 효과 검증은 이번 검증에 포함되지 않는다. 지도안은 단원 데이터와 공통 교수 틀을 활용한 초안이며 전 차시의 독립적인 출판 검수 완료를 의미하지 않는다.

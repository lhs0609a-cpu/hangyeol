### 수용 기준 — B-02 중복 방지

```
GIVEN 강사 T가 학생 email=a@x.com 을 이미 등록했고 상태가 completed
WHEN  같은 강사가 같은 이메일을 재등록 시도
THEN  기존 레코드가 재활성화되고 새 과금이 발생하지 않는다
AND   "이미 등록된 학생입니다. 이어서 진행합니다" 안내
```

```
GIVEN 강사가 학생 A 레코드로 다른 사람 B·C를 돌려쓰려 함
WHEN  4차시 진입 시점에 student.verified_at 이 NULL
THEN  자료 열람이 차단되고 "학생에게 인증 링크를 다시 보내세요" 표시

| C-05 | 복습 슬라이드 자동 생성 | P1 | **직전 리포트의 expression 항목이 그대로 복습 문항이 됨** |
| C-06 | 차시 자료 열람 | P0 | 슬라이드 뷰어. 다운로드·인쇄·우클릭 차단, 워터마크 상시 |
| C-07 | 목표 수행 판정 | P0 | 통과 → 다음 차시 해제 / 재수행 → 같은 차시 유지 |
| C-08 | 3분 수업 리포트 | P0 | 새 표현 ≤5, 오답 ≤3, 통과 여부. **STT 미사용** |

| C-10 | 2주 공백 복귀 모드 | P2 | 14일 이상 공백 시 다음 수업은 복습 10분 모드로 자동 전환 |

### 수용 기준 — C-08 리포트

```
GIVEN 수업 종료
WHEN  강사가 새 표현 1개 이상 + 통과 여부를 입력하고 저장
THEN  lesson.report_submitted_at 기록
AND   각 expression 이 vocab_cards 로 적립되고 due_at = now + 1day
AND   학생에게 복습 알림 예약 (D+1, D+3, D+7, D+21, D+60)
AND   다음 수업의 복습 슬라이드에 해당 표현이 자동 편성
AND   외부 API 호출이 0건이다
```

### 수용 기준 — C-06 뷰어

```
· 우클릭 컨텍스트 메뉴 차단
· Ctrl/Cmd+S, Ctrl/Cmd+P 차단
· 이미지 드래그 차단, user-select: none
· 화면 우하단에 학생명 + 강사명 + 날짜 워터마크 상시 노출 (제거 불가)
· 자료 원본은 서명 URL(TTL 300초)로만 전달, 정적 경로 노출 금지
· asset_views 에 열람 로그 기록 (teacher_id, student_id, unit_id, ip_hash)
· student_id 없이 unit 열람 요청 시 403
```

## D. 학생 학습 페이지 — **P0 자물쇠**

화이트라벨. "○○ 선생님의 학습 노트"로만 표시. **우리 브랜드·예약·결제 절대 노출 금지.**

| ID | 기능 | P | 설명 |
|---|---|---|---|
| D-01 | 학습노트 홈 | P0 | 오늘의 과제 4개 + 한글 음절 진도 + 지난 수업 + 진도 요약 |
| D-02 | 이메일 인증 | P0 | 매직링크. 비밀번호 없음 |
| D-03 | SRS 복습 카드 | P1 | 뒤집기 → 어려움/보통/쉬움 → 간격 재계산 |
| D-04 | HVPT 소리 구분 | P1 | 5개 대립쌍, 화자 8, 2~3지선다, 즉각 교정 피드백 |
| D-05 | 4·3·2 유창성 | P1 | 240→180→120초 타이머, 주제 제시 |
| D-06 | 다청 (그냥 듣기) | P2 | 레벨별 3~5분 오디오 목록 |
| D-07 | 워크북 PDF | P2 | 차시당 2장, QR 음원 연동 |
| D-08 | 진도 대시보드 | P1 | TOPIK 추정·누적어휘·소리구분 점수·발화비율 추이 |
| D-09 | 개인 단어장 | P1 | 수업 표현 자동 적립. 그 표현이 나온 수업 음성 클립 첨부 |
| D-10 | 학습 알림 | P1 | D+1/3/7/21/60 푸시 (이메일 · 웹푸시) |

### 수용 기준 — D-01 한글 음절 진도

```
GIVEN 오늘 과제 4개 중 2개 완료
WHEN  학습노트 홈 진입
THEN  '한' 글자의 획 중 ㅎ(꼭지·가로획·ㅇ)까지 그려진 상태로 표시
AND   과제 완료 시 해당 획이 stroke-dashoffset 애니메이션으로 그어진다
AND   prefers-reduced-motion 시 애니메이션 없이 즉시 표시
```

### 화이트라벨 검사 항목 (릴리즈 게이트)

```
□ 페이지 어디에도 '사맛' 문자열 없음 (옛 이름 '한결' 도 함께 막는다)

□ 예약 버튼 없음
□ 결제·충전 UI 없음
□ 다른 강사 목록·검색 없음
